# Справочник по конфигурации

Назначение: все флаги движка, ключи настроек, переменные окружения и расположение файлов VoiceMate. Назад к [README](../README.ru.md).

## Откуда берутся настройки

| Часть | Источник | Приоритет |
|---|---|---|
| Движок | Флаги командной строки `voice-mate` (`make run ARGS="..."`) и `~/.config/voicemate/config.toml` (записывается командами `make setup` и `make configure`) | Флаг, затем `config.toml`, затем определение или встроенное значение по умолчанию |
| Компаньон | `companion.toml`, который редактируется через Настройки | Файл; недопустимые значения заменяются значением по умолчанию |

Флаги попадают в движок через Makefile с помощью `ARGS`, например `make run ARGS="--model medium --no-tts"`. `make` не передаёт слова, написанные после цели, поэтому всегда используйте `ARGS`.

## Флаги движка

### Распознавание речи и ввод

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--model {tiny,base,small,medium,large-v2,large-v3,large-v3-turbo}` | `large-v3-turbo` | Модель Whisper |
| `--hotkey` | `ctrl+alt+v` | Горячая клавиша режима буфера обмена |
| `--cpu` | выкл. | Принудительно использовать CPU (int8). Важнее любых настроек GPU |
| `--stt-mode {auto,cpu,gpu}` | сохранённый выбор, иначе `auto` | Где расшифровывать. `cpu`: faster-whisper int8 на процессоре, жадное декодирование с VAD, GPU остаётся свободной для другой работы. `gpu`: бэкенд GPU с жадным декодированием, а если он не работает, переход на CPU (с подсказкой по установке). `auto`: GPU, когда её бэкенд работает, иначе CPU. См. [Режимы распознавания речи](#режимы-распознавания-речи) |
| `--cpu-threads` | `0` (половина ядер, не больше 8) | Потоки CPU для faster-whisper на CPU |
| `--gpu-backend {auto,nvidia,amd,cpu}` | сохранённый выбор, иначе определённый | Производитель GPU; `auto` определяет карту |
| `--whisper-backend {faster-whisper,whispercpp,openai-whisper}` | сохранённый выбор, иначе по производителю | Движок распознавания речи |
| `--stt-strategy {auto,faster-whisper-rocm,whispercpp,openai-whisper}` | сохранённый выбор, иначе `auto` | Только AMD: первый бэкенд цепочки резервных вариантов |
| `--whispercpp-mode {server,cli}` | `server` | `server` держит модель whisper.cpp загруженной; `cli` загружает её заново для каждой записи (медленнее) |
| `--transcription-language {auto,pt,en,es,fr,de,it,ja,ru,zh}` | выводится из `--output-lang` | Язык, закреплённый для расшифровки. `auto` определяет его для каждой записи (менее стабильно на коротких записях) |
| `--input-method {keyboard,mouse}` | `keyboard` | `mouse` работает только в Windows (триггер `keyboard-hooks`) и только для режима буфера обмена; он отключает режим Claude |
| `--mouse-button` | `x` | Кнопка мыши для `--input-method mouse` (`x` это боковая кнопка) |
| `--max-recording-seconds` | `600` | Предел длительности записи. При 80 % звучит предупреждение; на пределе запись останавливается и расшифровывается |
| `--output-lang` | `pt-BR` | Код BCP-47. Язык ответов Claude, язык расшифровки по умолчанию (`pt-BR` даёт `pt`, `en` даёт `en`, `zh-CN` даёт `zh`) и язык сообщений движка по умолчанию. По умолчанию Whisper закрепляется на португальском: передайте `--output-lang en` (или `--transcription-language en`), когда диктуете по-английски. Для движка, который запускает компаньон, он передаёт его сам, исходя из настройки «Язык диктовки:» |
| `--stt-engine {builtin,external}` | сохранённый выбор, иначе `builtin` | `builtin` это движок распознавания речи, выбранный выше. `external` это сервис, который вы запускаете ([протокол](stt-provider-protocol.ru.md)) |
| `--stt-url` | `http://127.0.0.1:8766` | Только `external`: базовый URL провайдера. Недопустимый URL фиксируется в журнале, и используется встроенный движок |
| `--stt-options` | нет | Только `external`: JSON-объект параметров, которые передаются провайдеру как есть |
| `--no-stt-fallback` | выкл. | Только `external`: запись, которую провайдер не смог расшифровать, завершается ошибкой, а не уходит во встроенный движок |

Токен STT-провайдера никогда не передаётся флагом: он читается из `VOICEMATE_STT_TOKEN`, а если её нет, из `stt_external_token` в файле движка, и никогда не записывается в журнал. Его команда запуска берётся только из `VOICEMATE_STT_START_COMMAND`. Движок удаляет обе переменные из своего окружения после чтения. См. [протокол STT-провайдера](stt-provider-protocol.ru.md).

### Платформа, триггер и API

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--platform {windows,linux-x11,linux-wayland,wsl2}` | сохранённый выбор, иначе определённый | Среда выполнения |
| `--trigger {keyboard-hooks,pynput,evdev,socket}` | по платформе: `windows` использует `keyboard-hooks`, `linux-x11` использует `pynput`, `linux-wayland` использует `evdev`, `wsl2` использует `socket` | Как горячие клавиши доходят до движка. `socket` означает, что триггером служит HTTP API |
| `--daemon-port` | сохранённый выбор, иначе `47821` | Порт локального HTTP API |
| `--api` | выкл. (всегда включён с `--trigger socket`) | Запускать HTTP API рядом с нативным слушателем горячих клавиш |
| `--api-token` | выкл. | Требовать `Authorization: Bearer <token>` на каждом маршруте, кроме `/health` (файл токена ниже) |
| `--supervised` | выкл. | Корректно завершаться, когда stdin доходит до конца файла (компаньон держит stdin открытым) |
| `--no-watchdog` | сторожевой таймер включён | Отключить сторожевой таймер, который перезапускает зависший движок |
| `--watchdog-timeout` | `120` | Таймаут сторожевого таймера в секундах |
| `--no-listener-refresh` | обновление включено | Только Windows: отключить периодическую переустановку перехватчика клавиатуры |
| `--listener-refresh-seconds` | `60` | Только Windows: интервал этой переустановки |

`make run-engine` выполняет `voice-mate --supervised --api --api-token`; именно это запускает компаньон.

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--no-tts` | выкл. | Без голосового ответа; ответ по-прежнему попадает в буфер обмена |
| `--tts-engine {<default>,kokoro,voxcpm,external,none}` | сохранённый выбор, иначе движок по умолчанию | Движок TTS. `external` это сервис, который вы запускаете ([протокол](tts-provider-protocol.md)). `none` отключает TTS |
| `--tts-url` | `http://127.0.0.1:8765` | Только `external`: базовый URL провайдера |
| `--tts-external-voice` | по умолчанию у провайдера | Только `external`: идентификатор голоса (его заполняет выбор голоса в компаньоне) |
| `--tts-options` | нет | Только `external`: JSON-объект, который передаётся провайдеру как `options` (скорость, стиль). Всё остальное игнорируется с предупреждением |
| `--tts-kokoro-voice` | `pf_dora` | Голос Kokoro. Португальские голоса: `pf_dora` (женский), `pm_alex` и `pm_santa` (мужские) |
| `--tts-voice` | описание на португальском языке голоса пожилой бразильянки | Только VoxCPM2: текстовое описание голоса, используется, когда нет образца голоса |
| `--tts-cfg-value` | `2.0` | `cfg_value` VoxCPM2 (от 1.0 до 3.0) |
| `--tts-inference-timesteps` | `10` | Шаги вывода VoxCPM2 (от 4 до 30) |
| `--tts-device {auto,cuda,cpu,mps}` | `auto` | Устройство для TTS |
| `--tts-save-dir` | нет | Сохранять каждый сгенерированный аудиофайл в эту папку |
| `--tts-no-streaming` | выкл. | Генерировать за один проход вместо потоковой передачи (для отладки) |
| `--tts-voice-seed-mode {auto,fixed,off}` | `off` | Как движок по умолчанию и VoxCPM2 выбирают голос (см. [usage.md](usage.ru.md#режимы-образца-голоса)) |
| `--tts-voice-seed-path`, `--tts-voice-seed-text` | нет | Образец WAV и его точный текст, обязательны для `fixed` |
| `--tts-voice-seed-cache-dir` | `~/.cache/voicemate` | Куда `auto` сохраняет свой образец |
| `--tts-reset-seed` | выкл. | Удалить автообразец VoxCPM2 (`voice_seed.wav`) перед запуском |
| `--tts-show-progress` | выкл. | Показывать индикатор выполнения VoxCPM2 |
| `--tts-drain-timeout-seconds` | `60.0` | Таймаут опустошения аудиоплеера |
| `--tts-debug-vram` | выкл. | Записывать в журнал использование VRAM вокруг каждого предложения |

Токен провайдера никогда не передаётся флагом: он читается из `VOICEMATE_TTS_TOKEN`, а если её нет, из `tts_external_token` в файле движка, и никогда не записывается в журнал. Компаньон передаёт его в окружении, а движок удаляет его из своего окружения после чтения. В `companion.toml` компаньона он хранится открытым текстом.

Команда запуска провайдера тоже не флаг: движок читает её из `VOICEMATE_TTS_START_COMMAND`, удаляет из своего окружения после чтения и никогда не записывает в журнал. См. [Запуск провайдера](tts-provider-protocol.md#starting-the-provider-with-voicemate).

Компаньон передаёт адрес и голос как `--tts-url=...` и `--tts-external-voice=...`, со знаком `=`, чтобы значение, которое начинается с `-`, не читалось как флаг.

TTS запускается только когда включён один из режимов диалога, и его прогрев тоже: встроенный голос Kokoro в остальных случаях не прогревается. Если пакетов выбранного движка нет или движок не запускается, он записывает в журнал предупреждение с подсказкой по исправлению и работает без TTS.

## Файл движка: `~/.config/voicemate/config.toml`

Плоский файл TOML, который записывают `make setup` и `make configure`. Недопустимые значения игнорируются; отсутствующий или повреждённый файл означает «ничего не сохранено». Каждый ключ необязателен.

| Ключ | Значения | Описание |
|---|---|---|
| `gpu_vendor` | `nvidia`, `amd`, `cpu` | Производитель GPU |
| `whisper_backend` | `faster-whisper`, `whispercpp`, `openai-whisper` | Движок распознавания речи |
| `tts_enabled` | `true`, `false` | TTS включён или выключен |
| `tts_engine` | движок по умолчанию, `kokoro`, `voxcpm`, `external`, `none` | Движок TTS |
| `tts_external_url`, `tts_external_voice`, `tts_external_options` | текст | Настройки движка `external` (адрес, идентификатор голоса, параметры JSON) |
| `tts_external_token` | текст | Bearer-токен движка `external`. Открытым текстом в этом файле; `VOICEMATE_TTS_TOKEN` важнее |
| `stt_engine` | `builtin`, `external` | Движок распознавания |
| `stt_external_url`, `stt_external_options` | текст | Настройки внешнего движка распознавания (адрес, параметры JSON) |
| `stt_external_token` | текст | Bearer-токен внешнего движка распознавания. Открытым текстом в этом файле; `VOICEMATE_STT_TOKEN` важнее |
| `stt_fallback` | `true`, `false` | `false` отключает встроенный резервный вариант внешнего движка распознавания |
| `default_flow` | `clipboard`, `claude_chat` | `clipboard` отключает режим Claude |
| `platform` | `windows`, `linux-x11`, `linux-wayland`, `wsl2` | Среда выполнения |
| `trigger` | `keyboard-hooks`, `pynput`, `evdev`, `socket` | Механизм горячих клавиш |
| `stt_strategy` | `auto`, `faster-whisper-rocm`, `whispercpp`, `openai-whisper` | Цепочка резервных вариантов для AMD |
| `ct2_rocm_ok` | `true`, `false` | CTranslate2-ROCm проверен при настройке. Движок записывает `false`, когда он даёт сбой во время работы; `make configure` пробует снова |
| `daemon_port` | целое число | Порт HTTP API |
| `stt_mode` | `auto`, `cpu`, `gpu` | Режим распознавания по умолчанию (спрашивается командами `make setup` и `make configure`) |

Смена языка вызывает вопрос «Перезапустить VoiceMate?» («Перезапустить сейчас» или «Позже»); до перезапуска вкладка «Общие» показывает «Вступит в силу после перезапуска VoiceMate.».

### Язык диктовки

Компаньон превращает `dictation_language` в два флага для движка, который он запускает: `--transcription-language <code>` и `--output-lang <BCP-47>` (`pt` даёт `pt-BR`, `zh` даёт `zh-CN`, остальные дают собственный код). `interface` берёт язык интерфейса; `auto` передаёт `--transcription-language auto` и оставляет `--output-lang` на языке интерфейса, так что Claude по-прежнему отвечает на нём. Смена ключа перезапускает движок. В режиме «Только подключаться» ключ игнорируется, и движок сохраняет свои флаги; то же верно для движка, к которому компаньон подключается (служба systemd или запущенный вручную). Подробнее в [usage.md](usage.ru.md#язык-диктовки).

## Режимы распознавания речи

Движок расшифровывает речь либо на процессоре, либо на видеокарте. Режим CPU существует для того, чтобы
VoiceMate продолжал работать, пока GPU занята другой работой (монтаж видео, рендеринг, игры):
он никогда ничего не загружает на GPU.

| Режим | Бэкенд | Декодирование | Когда |
|---|---|---|---|
| `cpu` | faster-whisper, int8 | beam 1, фильтр VAD, `--cpu-threads` | GPU занята или её нет |
| `gpu` | faster-whisper CUDA (NVIDIA), openai-whisper ROCm (AMD в WSL2), whisper.cpp Vulkan (AMD в Windows) | beam 1 | быстрее всего |
| `auto` | выбор, сделанный при настройке движка | значение по умолчанию бэкенда (beam 5) | как было до появления этой опции |

Компаньон хранит по одной модели на режим (`stt_cpu_model`, `stt_gpu_model`) и передаёт
`--stt-mode` и `--model` движку, который запускает. Переключение перезапускает движок, а именно
это освобождает (или занимает) GPU. Режим, который не установлен, компаньон устанавливает
после вопроса, с указанием размера загрузки; те же инструменты, запущенные вручную:

```bash
make stt-check
make stt-install MODE=gpu
make stt-install MODE=cpu ARGS="--model medium"
```

`stt-install` затрагивает только собственное виртуальное окружение движка (и `~/.cache` для
моделей): ROCm PyTorch и openai-whisper для AMD, библиотеки CUDA для NVIDIA,
сборку whisper.cpp в Windows, модель faster-whisper для CPU.

### Тест скорости

Измерено 2026-10-27 (CPU) и 2026-10-28 (GPU) на португальской диктовке из Common
Voice (короткие записи около 6 с, длинные около 65 с) через собственные
бэкенды движка на одной машине (Intel i5-13400F, AMD Radeon RX 9070 XT с ROCm в WSL2). WER это
доля ошибочных слов относительно эталонного текста; задержка это время расшифровки на
одну запись.

| Режим | Модель | Beam | Короткие: задержка, WER | Длинные: задержка, WER |
|---|---|---|---|---|
| CPU (8 потоков, int8) | large-v3-turbo | 1 | 4,7 с, 5,0 % | 21 с, 3,3 % |
| CPU (8 потоков, int8) | medium | 1 | 3,2 с, 5,3 % | 15 с, 5,1 % |
| GPU (Radeon, ROCm) | large-v3-turbo | 5 | 0,45 с, 4,8 % | 4,6 с, 2,9 % |
| GPU (Radeon, ROCm) | large-v3-turbo | 1 | 0,18 с, 4,5 % | 1,9 с, 3,6 % |
| GPU (Radeon, ROCm) | medium | 5 | 0,83 с, 6,1 % | 10,1 с, 6,9 % |
| GPU (Radeon, ROCm) | medium | 1 | 0,42 с, 5,8 % | 4,9 с, 7,3 % |

На CPU beam 5 в том же прогоне не дал более низкого WER и лишь работал медленнее (в
таблицу не включён). На GPU жадное декодирование примерно в 2,4 раза быстрее, чем beam 5, при потере менее
одного пункта WER, поэтому режим `gpu` декодирует жадно. `medium` менее точна, чем
`large-v3-turbo` в обоих случаях, а на GPU ещё и медленнее, поэтому модель turbo
используется по умолчанию в обоих режимах; `medium` и `small` предназначены для более слабых процессоров.

Горячие клавиши ассистента проверяются вместе с остальными: сочетание нельзя назначить двум действиям.

Что делает изменение, пока ассистент работает:

| Изменение | Результат |
|---|---|
| `mode`, `skill_language`, `custom_skill_dir` и, в собственном режиме, `effort` и `permission_mode` | Перезапускает центральный разговор |
| `desktop_conversation` (режим Desktop) | Перезапускает центральный разговор |
| `model` (собственный режим) | Действует со следующего ответа, без перезапуска |
| `model` или `effort` (режим Desktop) | VoiceMate не может изменить разговор Desktop; он отправляет центральному заметку с просьбой применить их к себе |
| `permission_mode` | Действует на разговоры, которые ассистент запускает с этого момента, и сразу перезапускает центральный разговор (собственный режим), так что он никогда не сохраняет старые разрешения |
| Имя, личность, хранилище, теги, `answer_delivery` | Записываются в `assistant.json`, который навык перечитывает |

Текст, который вы пишете для «Написать свою», не хранится в `companion.toml`: VoiceMate держит его в `assistant-personality.md` в своей папке состояния (до 20 000 символов) и передаёт навыку этот файл как `personality_file`.

> [!WARNING]
> `permission_mode = "bypassPermissions"` позволяет каждому разговору, который запускает ассистент, менять любые файлы и выполнять любые команды на этом компьютере без вопросов. Выбрать его можно только в окне Настроек: голосом ассистент может переключаться только между `default` и `acceptEdits`. Он никогда не применяется к закрытой сессии, которую ассистент возобновляет: при таком возобновлении режим разрешений не передаётся, пока вы не зададите `resume_permission_mode`, который отклоняет `bypassPermissions`.

Ответы ассистента озвучивает движок голосом, настроенным в движке (вкладка «Голос» или `--tts-engine` движка): компаньон отправляет блок `<voice>` каждого ответа, предложение за предложением, на эндпоинт `/tts` движка ([tts-provider-protocol.md](tts-provider-protocol.md#the-engine-speaks-the-same-protocol)) и воспроизводит звук на этом компьютере.

Говорить за ассистента могут встроенный голос Kokoro и свой провайдер, а также голоса, которые в Windows уже есть (все языки, установленные в Параметры > Время и язык > Речь), и ничего скачивать не нужно. Выбирает «Источник голоса:»: `auto` использует голос движка и голоса Windows, когда движок не может говорить (или у него нет голоса), `engine` только движок, `windows` только Windows. **Загрузить голоса** и **Проверить** следуют выбранному источнику ещё до сохранения; идентификатор голоса принадлежит одному источнику, и каждый источник игнорирует идентификаторы другого. Когда говорить нечем, ответы остаются только текстом, а окно ассистента показывает одно уведомление «Голос недоступен» с причиной. «Stop talking», новая просьба и смена режима заглушают голос сразу. Он никогда не говорит поверх записи: то, что приходит, пока микрофон записывает или пока запись расшифровывается, ждёт; предложение, которое оборвала запись, произносится заново с начала, а за ним по порядку идут предложения, уже стоявшие за ним в очереди.

VoiceMate также записывает `~/.voicemate/assistant.json` в вашей пользовательской папке: это файл, который читает навык `voicemate-assistant` (`version`, `language`, `user_name`, `personality_file`, `notes_vault`, `expressions`, `mode`, `permission_mode`, `resume_permission_mode`, `answer_delivery`, `instructions`, `inbox` и каталог `settings`). С португальским навыком `language` равен `"pt-BR"`, и голос говорит по-португальски (pt-BR), каким бы ни был язык интерфейса. С английским навыком (или своим) язык следует за интерфейсом.

`pending` перечисляет запросы, которых ассистент ждёт или за которыми наблюдает (идентификатор сессии, название, причина, с какого времени, `watch`, `until`), а `instructions` постоянные инструкции, которые вы ему дали ([assistant.md](assistant.ru.md#-постоянные-инструкции)). Его формат описан в [usage.md](usage.ru.md#навык). Сам навык устанавливается в `<Claude home>/skills/voicemate-assistant`, где Claude home это `~/.claude` или папка из `CLAUDE_CONFIG_DIR`.

### Настройки, которые ассистент может менять голосом

Список `settings` в `assistant.json` это единственный список, который ассистент может менять.

Ключи ассистента: `assistant.mode` (`own_session`, `desktop`), `assistant.model`, `assistant.effort`, `assistant.permission_mode`, `assistant.answer_delivery`, `assistant.new_conversation_model`, `assistant.new_conversation_effort`, `assistant.desktop_conversation`.

Ключи голоса, текста и звуков: `assistant.speak_replies`, `assistant.voice`, `assistant.voice_commands`, `assistant.expressions`, `assistant.user_name`, `assistant.personality_source`, `assistant.desktop_profile_auto_update`, `assistant.skill_language`, `cues.enabled`, `cues.volume` (от 0 до 100), `cues.answer.enabled`, `cues.answer.volume` (от 0 до 100), `general.dictation_language`, `general.stt_mode` и `general.notify_level`.

Намеренно не включены: горячие клавиши; любые файлы и папки (файл и текст личности, хранилище, папка своего навыка, импортированный профиль Desktop); движок голоса, адрес провайдера и токен; сам движок (папка, дистрибутив WSL, порт, режим); режим `off`; и звуковые сигналы, кроме сигнала ответа. Значение должно быть одним из перечисленных (текст это одна строка не длиннее 200 символов), для `desktop` нужен выбранный разговор Desktop, а для `personality_source` `file` нужен выбранный файл; иначе VoiceMate отказывает с указанием причины и сообщает об этом ассистенту.

## Токен API и порт

- HTTP API слушает только `127.0.0.1`, по умолчанию порт `47821`. WSL2 пробрасывает его на loopback Windows.
- Запросы с заголовком `Origin` (браузеры) или с `Host`, который не является loopback, получают `403`. `/trigger` принимает только POST.
- С `--api-token` движок создаёт `~/.config/voicemate/api-token` (режим 0600, 32 случайных байта), если файла нет, и каждый маршрут, кроме `/health`, требует `Authorization: Bearer <token>`. В Windows компаньон читает файл через `wsl.exe` и читает его снова после отказа, не чаще раза в 30 секунд.
- `make run` и служба systemd работают без токена; `make run-engine` (компаньон) работает с ним. Старые скрипты горячих клавиш работают только с движком без токена.
