# VoiceMate 0.2.0: release notes

VoiceMate 0.2.0 adds a voice assistant that keeps track of your other Claude conversations, lets you choose where speech-to-text runs (CPU or GPU), and opens the voice output to any text-to-speech service through a small HTTP protocol. Dictation to the clipboard works as before.

## Highlights

- **Voice assistant (experimental, off by default):** one Claude conversation, the central one, that you talk to with `Ctrl+Alt+S` or type to in its window (`Ctrl+Alt+W`, or the new **Assistant** button in the status window). It lists and reads your other Claude conversations, asks them things, starts new ones in the background and tells you when they answer. Two modes: **VoiceMate's own conversation** (a Claude Code process VoiceMate owns, also shown in Claude Desktop and on the phone through Remote Control) or **A Claude Desktop conversation** you already have.
- **Answers from other conversations:** spoken as soon as they arrive, or held in an inbox with a short notice, a sound or nothing at all. `Ctrl+Alt+R` (**Hear what's ready**) gives one spoken summary of everything waiting, and a blue badge on the tray icon shows the count.
- **Direct mode and voice commands** in English, Portuguese and Spanish: "talk directly to the conversation X" sends your words as they are to that conversation; "back to the assistant", "read the last answer", "stop talking" and others run without any AI.
- **Settings by voice:** ask the assistant to change the answer delivery, the model, the voice and about twenty other settings.
- **CPU or GPU transcription:** switch from the tray menu (**Transcription**) or the settings window. CPU (faster-whisper int8 with VAD) leaves the GPU free for other work; GPU is the fastest. A mode that is not installed is installed after asking, with the download size.
- **Custom voice provider:** the new **Voice** tab connects the engine to any text-to-speech service that follows the `voicemate-tts` protocol ([docs/tts-provider-protocol.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/tts-provider-protocol.md)), with a voice picker loaded from the provider and a **Test voice** button. The assistant's replies are spoken sentence by sentence through it, or through Kokoro.
- **Steadier recording:** a microphone open that the audio system refuses is tried again by itself before "Microphone unavailable" shows.

## Requirements

- As in 0.1.0: Windows 11, or Windows 10 build 19044 or newer, 64-bit, with WSL2 and WSLg, and the engine set up from source inside WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/wsl2.md)).
- For the voice assistant: the Claude Code CLI on Windows (the `claude` command), signed in once with `claude auth login`. For the Desktop mode, Claude Desktop open with the screen unlocked.

## Upgrading from 0.1.0

1. Update the engine inside WSL, in the folder where you cloned VoiceMate:

   ```bash
   cd ~/voice-mate
   git pull
   make setup    # installs the new dependencies; it asks for the default transcription mode
   make doctor
   ```

   The new tray app needs this engine for the transcription modes and the spoken replies. With an older engine, dictation still works, but the replies stay text only.

2. Download and check the installer (step 2 below), then run it. It replaces 0.1.0 in place and keeps your settings, hotkeys and the **Not copied** list. Quit VoiceMate first if the installer asks you to.

## How to install (first time)

The installer contains the tray app. The speech engine runs inside WSL2 and is set up once from source; the tray app then starts it for you.

### 1. Set up the engine in WSL2 (once)

1. In Windows, update WSL: `wsl --update`. WSLg, which gives WSL access to your microphone, comes with it.
2. With an AMD GPU: install the AMD Adrenalin driver 26.2.2 or newer in Windows, then ROCm for WSL (track 7.2) inside Ubuntu, following [AMD's guide](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). `rocminfo` must list your GPU.
3. Inside Ubuntu, install the audio and build packages:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Make sure Python 3.12 and [Poetry](https://python-poetry.org/docs/#installation) are installed, then clone VoiceMate into your home folder and run the setup:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detects WSL2 and the GPU, installs the matching PyTorch and the modules you pick
   make doctor   # checks microphone, audio, GPU and binaries, with a fix for each problem
   ```

   `make setup` asks for the default transcription mode (CPU or GPU); you can switch later from the tray menu. It may also offer a systemd service that starts the engine with WSL. You do not need it with the tray app.

More detail and troubleshooting: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/wsl2.md).

### 2. Download and check the installer

Download `VoiceMate-Setup-0.2.0.exe` and its `.sha256` file from the release page. In PowerShell, in the download folder:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.2.0.exe -Algorithm SHA256).Hash
```

The value must match the one in the `.sha256` file (upper or lower case does not matter). If it does not, do not run the file and download it again.

### 3. Run the installer

1. Open `VoiceMate-Setup-0.2.0.exe`. The installer is not code-signed, so Windows SmartScreen may warn on first run: choose **More info**, then **Run anyway**.
2. The installer starts in your Windows display language when it is one of the five; otherwise it asks you to pick one. VoiceMate installs for your user only, without an administrator prompt, into `%LOCALAPPDATA%\Programs\VoiceMate`, and adds itself to the Start menu.
3. Optionally create a desktop shortcut and let VoiceMate start when you sign in, then finish and launch VoiceMate.

### 4. First run

1. The VoiceMate icon appears in the tray. While the engine loads the model (10 to 60 seconds), VoiceMate shows "Starting engine...".
2. If it shows "Engine folder not found", open **Settings...** > **General** and set **WSL distro** and **Engine folder**.
3. Try dictation: press `Ctrl+Alt+V`, speak, press `Ctrl+Alt+V` again, and paste with `Ctrl+V`.
4. If the microphone does not work, open Windows **Settings** > **Privacy & security** > **Microphone** (**Privacy** on Windows 10) and allow desktop apps to use it. If audio stays stuck, use the tray menu > **Engine** > **Restart WSL...**, or run `wsl --shutdown`.

### 5. Turn on the voice assistant (optional)

1. Install the [Claude Code CLI](https://docs.claude.com/en/docs/claude-code) on Windows and run `claude auth login` once in a terminal.
2. Press the **Assistant** button in the status window (or `Ctrl+Alt+W`). While the assistant is off, its window says how to turn it on.
3. In **Settings...** > **Assistant**, choose the **Assistant mode:**. For **A Claude Desktop conversation**, type the exact title of that conversation in **Desktop conversation:**.
4. Press `Ctrl+Alt+S`, ask "what are my conversations doing?", and press `Ctrl+Alt+S` again.

The whole flow, with diagrams: [docs/usage.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/usage.md#voice-assistant-experimental).

### 6. Pin to the taskbar

Windows does not let installers pin apps. Open Start, search for VoiceMate, right-click it and choose **Pin to taskbar**.

## Known limitations

- The voice assistant is **experimental**. The Desktop mode types into Claude Desktop through Windows UI Automation: it takes the keyboard for about 2 seconds and clears any draft in that conversation's prompt.
- Conversations the assistant starts with **Full access, never ask (risky)** can change any file and run any command without asking. Keep the default unless you trust what you ask them to do.
- The installer is not code-signed, so SmartScreen warns on first run (see step 3).
- Linux, WSL2 and AMD support stays **experimental**: validated on a single AMD card (Radeon RX 9070 XT) under WSL2.
- When Windows loses its microphone, WSLg audio can hang until WSL restarts. The tray app can restart WSL for you, following **Restart WSL when audio fails**.
