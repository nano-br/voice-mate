# VoiceMate 0.2.0: notas de la versión

VoiceMate 0.2.0 añade un asistente de voz que sigue tus otras conversaciones de Claude, te deja elegir dónde se ejecuta la transcripción (CPU o GPU) y abre la salida de voz a cualquier servicio de texto a voz mediante un pequeño protocolo HTTP. El dictado al portapapeles funciona como antes.

## Lo más destacado

- **Asistente de voz (experimental, desactivado por defecto):** una conversación de Claude, la central, con la que hablas usando `Ctrl+Alt+S` o a la que escribes en su ventana (`Ctrl+Alt+W`, o el nuevo botón **Asistente** de la ventana de estado). Lista y lee tus otras conversaciones de Claude, les hace preguntas, inicia nuevas en segundo plano y te avisa cuando responden. Hay dos modos: **Conversación propia de VoiceMate** (un proceso de Claude Code que VoiceMate controla, que también se ve en Claude Desktop y en el móvil mediante Remote Control) o **Una conversación de Claude Desktop** que ya tengas.
- **Respuestas de otras conversaciones:** se dicen en cuanto llegan, o se guardan en una bandeja de entrada con un aviso breve, un sonido o nada. `Ctrl+Alt+R` (**Escuchar lo que está listo**) da un resumen hablado de todo lo que está esperando, y una insignia azul en el icono de la bandeja muestra la cantidad.
- **Modo directo y comandos de voz** en inglés, portugués y español: "habla directamente con la conversación X" envía tus palabras tal cual a esa conversación; "vuelve al asistente", "lee la última respuesta", "deja de hablar" y otros funcionan sin ninguna IA.
- **Configuración por voz:** pídele al asistente que cambie la entrega de las respuestas, el modelo, la voz y unos veinte ajustes más.
- **Transcripción en CPU o GPU:** cambia desde el menú de la bandeja (**Transcripción**) o desde la ventana de configuración. La CPU (faster-whisper int8 con VAD) deja libre la GPU para otros trabajos; la GPU es la más rápida. Un modo que no está instalado se instala después de preguntar, indicando el tamaño de la descarga.
- **Proveedor de voz personalizado:** la nueva pestaña **Voz** conecta el motor con cualquier servicio de texto a voz que siga el protocolo `voicemate-tts` ([docs/tts-provider-protocol.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/tts-provider-protocol.md)), con un selector de voz cargado desde el proveedor y un botón **Probar voz**. Las respuestas del asistente se dicen frase a frase a través de él, o de Kokoro.
- **Grabación más estable:** una apertura del micrófono que rechaza el sistema de audio se reintenta sola antes de mostrar "Micrófono no disponible".

## Requisitos

- Como en 0.1.0: Windows 11, o Windows 10 compilación 19044 o posterior, de 64 bits, con WSL2 y WSLg, y el motor configurado desde el código fuente dentro de WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/wsl2.md)).
- Para el asistente de voz: la CLI de Claude Code en Windows (el comando `claude`), con la sesión iniciada una vez mediante `claude auth login`. Para el modo Desktop, Claude Desktop abierto y la pantalla desbloqueada.

## Actualizar desde 0.1.0

1. Actualiza el motor dentro de WSL, en la carpeta donde clonaste VoiceMate:

   ```bash
   cd ~/voice-mate
   git pull
   make setup    # installs the new dependencies; it asks for the default transcription mode
   make doctor
   ```

   La nueva aplicación de bandeja necesita este motor para los modos de transcripción y las respuestas habladas. Con un motor antiguo, el dictado sigue funcionando, pero las respuestas quedan solo en texto.

2. Descarga y comprueba el instalador (paso 2 más abajo) y después ejecútalo. Reemplaza 0.1.0 en el mismo lugar y conserva tu configuración, los atajos y la lista **No copiadas**. Cierra VoiceMate antes si el instalador te lo pide.

## Cómo instalar (primera vez)

El instalador incluye la aplicación de bandeja. El motor de voz se ejecuta dentro de WSL2 y se configura una sola vez desde el código fuente; a partir de ahí la aplicación de bandeja lo inicia por ti.

### 1. Configura el motor en WSL2 (una sola vez)

1. En Windows, actualiza WSL: `wsl --update`. WSLg, que da a WSL acceso a tu micrófono, viene incluido.
2. Con una GPU AMD: instala en Windows el controlador AMD Adrenalin 26.2.2 o posterior y, dentro de Ubuntu, ROCm para WSL (versión 7.2), siguiendo la [guía de AMD](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). `rocminfo` debe mostrar tu GPU.
3. Dentro de Ubuntu, instala los paquetes de audio y de compilación:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Comprueba que tienes Python 3.12 y [Poetry](https://python-poetry.org/docs/#installation), clona VoiceMate en tu carpeta personal y ejecuta la configuración:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detects WSL2 and the GPU, installs the matching PyTorch and the modules you pick
   make doctor   # checks microphone, audio, GPU and binaries, with a fix for each problem
   ```

   `make setup` pregunta por el modo de transcripción predeterminado (CPU o GPU); puedes cambiarlo después desde el menú de la bandeja. También puede ofrecer un servicio de systemd que inicia el motor junto con WSL. Con la aplicación de bandeja no hace falta.

Más detalles y solución de problemas: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/wsl2.md).

### 2. Descarga y comprueba el instalador

Descarga `VoiceMate-Setup-0.2.0.exe` y su archivo `.sha256` desde la página de la versión. En PowerShell, en la carpeta de descargas:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.2.0.exe -Algorithm SHA256).Hash
```

El valor debe coincidir con el del archivo `.sha256` (da igual que esté en mayúsculas o minúsculas). Si no coincide, no ejecutes el archivo y vuelve a descargarlo.

### 3. Ejecuta el instalador

1. Abre `VoiceMate-Setup-0.2.0.exe`. El instalador no tiene firma de código, así que SmartScreen de Windows puede avisar la primera vez: elige **Más información** y luego **Ejecutar de todas formas**.
2. El instalador se abre en el idioma de visualización de Windows cuando es uno de los cinco; si no, te pide que elijas uno. VoiceMate se instala solo para tu usuario, sin permisos de administrador, en `%LOCALAPPDATA%\Programs\VoiceMate`, y se añade al menú Inicio.
3. Si quieres, crea un acceso directo en el escritorio y deja que VoiceMate se inicie al iniciar sesión; después termina y abre VoiceMate.

### 4. Primera ejecución

1. El icono de VoiceMate aparece en la bandeja. Mientras el motor carga el modelo (de 10 a 60 segundos), VoiceMate muestra "Iniciando el motor...".
2. Si aparece "No se encontró la carpeta del motor", abre **Configuración...** > **General** e indica **Distro de WSL** y **Carpeta del motor**.
3. Prueba el dictado: pulsa `Ctrl+Alt+V`, habla, vuelve a pulsar `Ctrl+Alt+V` y pega con `Ctrl+V`.
4. Si el micrófono no funciona, abre **Configuración** de Windows > **Privacidad y seguridad** > **Micrófono** (**Privacidad** en Windows 10) y permite que las aplicaciones de escritorio lo usen. Si el audio sigue bloqueado, usa el menú de la bandeja > **Motor** > **Reiniciar WSL...** o ejecuta `wsl --shutdown`.

### 5. Activa el asistente de voz (opcional)

1. Instala la [CLI de Claude Code](https://docs.claude.com/en/docs/claude-code) en Windows y ejecuta `claude auth login` una vez en una terminal.
2. Pulsa el botón **Asistente** de la ventana de estado (o `Ctrl+Alt+W`). Mientras el asistente está desactivado, su ventana explica cómo activarlo.
3. En **Configuración...** > **Asistente**, elige el **Modo del asistente:**. Para **Una conversación de Claude Desktop**, escribe el título exacto de esa conversación en **Conversación de Desktop:**.
4. Pulsa `Ctrl+Alt+S`, pregunta "¿qué están haciendo mis conversaciones?" y vuelve a pulsar `Ctrl+Alt+S`.

El flujo completo, con diagramas: [docs/usage.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/usage.md#voice-assistant-experimental).

### 6. Ancla VoiceMate a la barra de tareas

Windows no permite que los instaladores anclen aplicaciones. Abre Inicio, busca VoiceMate, haz clic derecho sobre él y elige **Anclar a la barra de tareas**.

## Limitaciones conocidas

- El asistente de voz es **experimental**. El modo Desktop escribe en Claude Desktop mediante la Automatización de la interfaz de usuario de Windows (UI Automation): toma el teclado durante unos 2 segundos y borra cualquier borrador del campo de texto de esa conversación.
- Las conversaciones que el asistente inicia con **Acceso total, nunca preguntar (arriesgado)** pueden modificar cualquier archivo y ejecutar cualquier comando sin preguntar. Mantén el valor predeterminado, a menos que confíes en lo que les pides.
- El instalador no tiene firma de código, así que SmartScreen avisa la primera vez (ver el paso 3).
- El soporte de Linux, WSL2 y AMD sigue siendo **experimental**: se validó con una sola tarjeta AMD (Radeon RX 9070 XT) en WSL2.
- Cuando Windows pierde el micrófono, el audio de WSLg puede bloquearse hasta que WSL se reinicie. La aplicación de bandeja puede reiniciar WSL por ti, según **Reiniciar WSL si falla el audio**.
