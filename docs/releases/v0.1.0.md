I built VoiceMate because speaking is much faster than typing: when you think out loud you give an AI far more context and detail than you would ever type. Press a hotkey, speak, paste. Whisper runs locally, so your voice never leaves your machine. I have used it every working day since March 2026, first on Windows with an NVIDIA card and, after switching to an AMD card, on WSL2, which is why that path is new here and still experimental.

This is the first public release.

## Highlights

- **Dictation to the clipboard:** `Ctrl+Alt+V` starts and stops recording, local Whisper transcribes, and the text is ready to paste into any app or AI tool.
- **Windows tray app (new):** VoiceMate now lives in the system tray. It starts and supervises the speech engine inside WSL2, owns the hotkeys, plays the sound cues and checks that every transcription really reached the clipboard. Anything that did not is kept under **Not copied**, even across restarts.
- **Per-user installer:** `VoiceMate-Setup-0.1.0.exe` installs without an administrator prompt and offers to start VoiceMate when you sign in.
- **Linux, WSL2 and AMD GPUs (experimental):** `make setup` detects NVIDIA, AMD or CPU and installs the matching PyTorch; on AMD a layered speech-to-text chain picks the best backend that works.
- **Five languages:** app, installer and README in English, Português (Brasil), Español, Русский and 简体中文.
- **Voice conversation with Claude (experimental):** `Ctrl+Alt+A` sends what you say to Claude and reads the answer aloud (OmniVoice by default, or Kokoro or VoxCPM2).
- **`make doctor`:** checks microphone, audio, GPU, whisper.cpp and the Claude CLI, and prints a fix for each problem it finds.

## Download

- **`VoiceMate-Setup-0.1.0.exe`**: the Windows tray app. Per-user install into `%LOCALAPPDATA%\Programs\VoiceMate`, Windows 10 version 1809 or newer, or Windows 11, 64-bit. A SHA-256 checksum is attached.
- The installer contains the tray app only. The speech engine runs inside WSL2 and is set up from source once (`git clone` and `make setup`), as described in [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.1.0/docs/wsl2.md) and the [README](https://github.com/nano-br/voice-mate/blob/v0.1.0/README.md). The tray app finds it in your WSL home folder and starts it for you.

## Requirements

- Windows 10 (1809 or newer) or Windows 11, 64-bit, with WSL2 and WSLg (`wsl --update`); the documented setup uses Ubuntu on Windows 11.
- Inside WSL: Python 3.12, Poetry, git and make, plus the audio and build packages listed in docs/wsl2.md.
- A GPU is strongly recommended. The WSL2 path was validated on an AMD Radeon RX 9070 XT with ROCm 7.2 for WSL and the AMD Adrenalin driver 26.2.2 or newer; `make setup` also offers NVIDIA (CUDA) and CPU.
- Only for the conversation with Claude: Node.js 18 or newer and the Claude Code CLI, installed and signed in inside WSL.
- Without the tray app, the engine still runs from source on Windows (the original NVIDIA path) and on native Linux; see the README.

## Known limitations

- Linux, WSL2 and AMD support is **experimental**: it has been validated on a single AMD card (Radeon RX 9070 XT) under WSL2.
- The installer is not code-signed, so Windows SmartScreen warns on first run: choose **More info**, then **Run anyway**. Check the SHA-256 checksum first if you want to be sure of the file.
- On Windows the tray app drives an engine inside WSL2. Running the engine natively on Windows under the tray app is planned for a later release.
- Transcription is pinned to Portuguese by default (derived from `--output-lang pt-BR`) and the tray app has no setting for it yet. To dictate in another language, start the engine yourself in WSL, for example `make run-engine ARGS="--output-lang en"`, and the tray app connects to it.
- On WSL2, whisper.cpp with Vulkan cannot use the GPU (Vulkan there is a software renderer), so AMD transcription goes through openai-whisper on ROCm. The faster CTranslate2-ROCm path is a heavy opt-in build.
- When Windows loses its microphone, WSLg audio can hang until WSL restarts. The tray app can restart WSL for you, following **Restart WSL when audio fails** in Settings.
- Windows does not let installers pin apps to the taskbar: open Start, search for VoiceMate, right-click it and choose **Pin to taskbar**.
- If one of the old hotkey scripts (PowerShell or AutoHotkey) is still running, the tray app shows "Used by another app": close the script and remove it from `shell:startup`.
- The voice conversation with Claude is experimental and needs a signed-in Claude Code CLI.
