# VoiceMate 0.2.0 发行说明

VoiceMate 0.2.0 新增了一个语音助手，它会跟踪你的其他 Claude 对话；你还可以选择语音转文字在 CPU 还是 GPU 上运行；语音输出也通过一个小型 HTTP 协议向任意文字转语音服务开放。听写到剪贴板的使用方式不变。

## 亮点

- **语音助手（实验性，默认关闭）**：一个核心 Claude 对话，你可以用 `Ctrl+Alt+S` 对它说话，或在它的窗口中打字（`Ctrl+Alt+W`，或状态窗口中新增的 **助手** 按钮）。它会列出并阅读你的其他 Claude 对话，向它们提问，在后台开启新对话，并在它们回答时告诉你。有两种模式：**VoiceMate 自己的对话**（由 VoiceMate 持有的 Claude Code 进程，也会显示在 Claude Desktop 中，并可通过 Remote Control 在手机上查看），或你已有的 **一个 Claude Desktop 对话**。
- **来自其他对话的回答**：一到就立即朗读，或存入收件箱，只给出简短提示、提示音，或完全不提示。`Ctrl+Alt+R`（**收听已就绪的内容**）会用语音概述所有待处理的内容，托盘图标上的蓝色角标显示数量。
- **直接模式和语音命令**，支持英语、葡萄牙语和西班牙语："talk directly to the conversation X"（直接与对话 X 交谈）会把你的话原样发送给该对话；"back to the assistant"（回到助手）、"read the last answer"（朗读最后一个回答）、"stop talking"（停止说话）等命令无需任何 AI 即可执行。
- **语音修改设置**：可以让助手修改回答的投递方式、模型、声音以及大约二十项其他设置。
- **CPU 或 GPU 转写**：可在托盘菜单（**转写**）或设置窗口中切换。CPU（faster-whisper int8 加 VAD）让 GPU 腾出来做其他工作；GPU 最快。尚未安装的模式会在询问后安装，并告知下载大小。
- **自定义声音提供方**：新的 **声音** 选项卡可把引擎连接到任何遵循 `voicemate-tts` 协议的文字转语音服务（[docs/tts-provider-protocol.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/tts-provider-protocol.md)），声音列表从提供方加载，并有 **试听声音** 按钮。助手的回答会通过它逐句朗读，也可以通过 Kokoro 朗读。
- **更稳定的录音**：当音频系统拒绝打开麦克风时，VoiceMate 会先自动重试，再显示“麦克风不可用”。

## 系统要求

- 与 0.1.0 相同：Windows 11，或 Windows 10 内部版本 19044 或更高，64 位，并安装 WSL2 和 WSLg，且已在 WSL 中从源码配置好引擎（[docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/wsl2.md)）。
- 使用语音助手需要：Windows 上的 Claude Code CLI（`claude` 命令），并已通过 `claude auth login` 登录一次。使用 Desktop 模式时，需要打开 Claude Desktop 且屏幕未锁定。

## 从 0.1.0 升级

1. 在 WSL 中更新引擎，进入你克隆 VoiceMate 的目录：

   ```bash
   cd ~/voice-mate
   git pull
   make setup    # installs the new dependencies; it asks for the default transcription mode
   make doctor
   ```

   新的托盘应用需要这个引擎来提供各种转写模式和语音回答。使用旧引擎时，听写仍可使用，但回答只有文字。

2. 下载并校验安装程序（见下文第 2 步），然后运行它。它会就地替换 0.1.0，并保留你的设置、快捷键和 **未复制** 列表。如果安装程序提示，请先退出 VoiceMate。

## 安装步骤（首次安装）

安装程序只包含托盘应用。语音引擎运行在 WSL2 中，需要从源码配置一次；之后由托盘应用替你启动。

### 1. 在 WSL2 中配置引擎（只需一次）

1. 在 Windows 中更新 WSL：`wsl --update`。WSLg 会随之安装，它让 WSL 能使用你的麦克风。
2. 如果使用 AMD 显卡：在 Windows 中安装 AMD Adrenalin 26.2.2 或更高版本的驱动，并按照 [AMD 官方指南](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html) 在 Ubuntu 中安装 WSL 版 ROCm（7.2 版本线）。`rocminfo` 应能列出你的 GPU。
3. 在 Ubuntu 中安装音频和编译所需的软件包：

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. 确认已安装 Python 3.12 和 [Poetry](https://python-poetry.org/docs/#installation)，然后把 VoiceMate 克隆到你的主目录并运行配置：

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detects WSL2 and the GPU, installs the matching PyTorch and the modules you pick
   make doctor   # checks microphone, audio, GPU and binaries, with a fix for each problem
   ```

   `make setup` 会询问默认的转写模式（CPU 或 GPU），之后可在托盘菜单中切换。它还可能提议安装一个随 WSL 启动引擎的 systemd 服务。使用托盘应用时不需要它。

更多细节和故障排查：[docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/wsl2.md)。

### 2. 下载并校验安装程序

从发布页面下载 `VoiceMate-Setup-0.2.0.exe` 及其 `.sha256` 文件。在下载目录中打开 PowerShell，运行：

```powershell
(Get-FileHash .\VoiceMate-Setup-0.2.0.exe -Algorithm SHA256).Hash
```

输出的值必须与 `.sha256` 文件中的值一致（不区分大小写）。如果不一致，请不要运行该文件，并重新下载。

### 3. 运行安装程序

1. 打开 `VoiceMate-Setup-0.2.0.exe`。安装程序没有代码签名，因此首次运行时 Windows SmartScreen 可能会发出警告：点击 **更多信息**，然后点击 **仍要运行**。
2. 如果 Windows 的显示语言是这五种之一，安装程序会直接使用该语言；否则会请你选择一种语言。VoiceMate 只为当前用户安装，无需管理员权限，安装位置为 `%LOCALAPPDATA%\Programs\VoiceMate`，并会添加到“开始”菜单。
3. 可以按需创建桌面快捷方式，并让 VoiceMate 在登录时启动；然后完成安装并打开 VoiceMate。

### 4. 首次运行

1. VoiceMate 图标会出现在托盘中。引擎加载模型期间（10 到 60 秒），VoiceMate 会显示“正在启动引擎...”。
2. 如果显示“未找到引擎文件夹”，请打开 **设置...** > **常规**，填写 **WSL 发行版** 和 **引擎文件夹**。
3. 试一试听写：按 `Ctrl+Alt+V`，说话，再按一次 `Ctrl+Alt+V`，然后用 `Ctrl+V` 粘贴。
4. 如果麦克风无法使用，请打开 Windows **设置** > **隐私和安全性** > **麦克风**（Windows 10 中为 **隐私**），允许桌面应用使用麦克风。如果音频仍然卡住，请使用托盘菜单 > **引擎** > **重启 WSL...**，或运行 `wsl --shutdown`。

### 5. 开启语音助手（可选）

1. 在 Windows 上安装 [Claude Code CLI](https://docs.claude.com/en/docs/claude-code)，并在终端中运行一次 `claude auth login`。
2. 点击状态窗口中的 **助手** 按钮（或按 `Ctrl+Alt+W`）。助手关闭时，它的窗口会说明如何开启。
3. 在 **设置...** > **助手** 中选择 **助手模式：**。如果选择 **一个 Claude Desktop 对话**，请在 **Desktop 对话：** 中输入该对话的准确标题。
4. 按 `Ctrl+Alt+S`，问一句 "what are my conversations doing?"（我的对话在做什么？），然后再按一次 `Ctrl+Alt+S`。

完整流程及图示：[docs/usage.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/usage.md#voice-assistant-experimental)。

### 6. 固定到任务栏

Windows 不允许安装程序固定应用。打开“开始”菜单，搜索 VoiceMate，右键单击它并选择 **固定到任务栏**。

## 已知限制

- 语音助手是**实验性**功能。Desktop 模式通过 Windows UI Automation 向 Claude Desktop 输入内容：它会占用键盘约 2 秒，并清除该对话输入框中的任何草稿。
- 助手以 **完全访问，从不询问（有风险）** 开启的对话，可以在不询问的情况下修改任何文件、运行任何命令。除非你信任交给它们的任务，否则请保持默认设置。
- 安装程序没有代码签名，因此首次运行时 SmartScreen 会发出警告（见第 3 步）。
- Linux、WSL2 和 AMD 支持仍是**实验性**的：目前只在一块 AMD 显卡（Radeon RX 9070 XT）上于 WSL2 中验证过。
- Windows 丢失麦克风后，WSLg 的音频可能会卡住，直到 WSL 重启。托盘应用可以按照 **音频故障时重启 WSL** 的设置替你重启 WSL。
