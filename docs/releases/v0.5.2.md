VoiceMate 0.5.2 is a round of fixes for the voice assistant: it no longer misses the answer to a message sent while a conversation was working, it knows whether a conversation is working or has finished, it reads and reports when you ask for news, it answers you at once and does the work after, and messages to Claude Desktop go out faster.

## Highlights

- **No answer is missed:** a message sent while a conversation was in the middle of a turn is taken in by that turn, and VoiceMate used to wait for a turn that never began, so the assistant was never told the answer had come. The end of that turn is now reported as the answer.

- **The assistant knows where a conversation stands:** it reads the conversation and sees whether it is working, has finished, or has been quiet for a long time. A conversation that had just summarized its context used to look stopped; its last messages are now read across the summary.

- **"Any news?" gets the news:** the assistant reads each conversation it is waiting for and tells you what it says, in the same reply, instead of asking whether you want it read.

- **It answers at once:** for a request that needs work, the assistant says one short line right away ("Got it, sending it now"), VoiceMate speaks that line when it is written, and the result is spoken when the work is done.

- **"Hear what's ready" speaks at once:** with VoiceMate's own conversation, the summary of an answer that is waiting for you is written while nobody waits, so asking to hear it costs no wait.

- **Faster messages to Claude Desktop:** finding the Claude Desktop window no longer waits for every other window on the screen. With a program that answers slowly, each message used to take many seconds longer.

## Download

- **`VoiceMate-Setup-0.5.2.exe`**: the Windows tray app. Per-user install into `%LOCALAPPDATA%\Programs\VoiceMate`; it replaces 0.5.1 in place and keeps your settings. The `.sha256` file next to it holds its SHA-256 checksum.
- The installer contains the tray app only. The speech engine runs inside WSL2 and is set up from source; if you already have it, update it as described in the release notes files (`git pull`, then `make setup`).

## Requirements

- As in 0.1.0: Windows 11, or Windows 10 build 19044 or newer, 64-bit, with WSL2 and WSLg, and the engine set up from source inside WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.5.2/docs/wsl2.md)).
- For the voice assistant: the Claude Code CLI on Windows (the `claude` command), signed in once with `claude auth login`. For the Desktop mode, Claude Desktop open with the screen unlocked.

## Known limitations

- The Desktop mode of the voice assistant types into Claude Desktop through Windows UI Automation: it takes the keyboard for about 2 seconds and clears any draft in that conversation's prompt.
- Conversations the assistant starts with **Full access, never ask (risky)** can change any file and run any command without asking. Keep the default unless you trust what you ask them to do.
- The installer is not code-signed, so SmartScreen warns on first run: choose **More info**, then **Run anyway**.
- AMD support is validated on a single card (Radeon RX 9070 XT) under WSL2, with ROCm 7.2.
- When Windows loses its microphone, WSLg audio can hang until WSL restarts. The tray app can restart WSL for you, following **Restart WSL when audio fails**.
