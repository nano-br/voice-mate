VoiceMate 0.5.3 makes the voice assistant tell you when a conversation it is waiting for stops getting anywhere, and keeps the conversations it opened when VoiceMate restarts.

## Highlights

- **A conversation that stops is reported:** when the turn of a conversation the assistant is waiting for dies on an error, the assistant is told and tells you at once, also when answers are held for later. Only a turn that ended normally used to be reported, so a conversation could stop with nobody told.

- **A conversation that goes quiet or in circles is reported:** when a turn has written nothing for 10 minutes, or the conversation summarized its context three times in the same turn, the assistant is told once, reads the conversation and tells you what it found.

- **Conversations survive a restart:** a conversation the assistant opened comes back after VoiceMate restarts while it was working. The process that had just been closed could still be listed as its owner, and the conversation came back as a new, empty one. When a conversation does continue under a new id, what the assistant waits for follows it.

- **An assistant that lost its instructions finds them again:** after its own conversation is summarized, the assistant could write its actions in the wrong shape. It is now told once to read its skill again (skill version 8).

## Download

- **`VoiceMate-Setup-0.5.3.exe`**: the Windows tray app. Per-user install into `%LOCALAPPDATA%\Programs\VoiceMate`; it replaces 0.5.2 in place and keeps your settings. The `.sha256` file next to it holds its SHA-256 checksum.
- The installer contains the tray app only. The speech engine runs inside WSL2 and is set up from source; if you already have it, update it as described in the release notes files (`git pull`, then `make setup`).

## Requirements

- As in 0.1.0: Windows 11, or Windows 10 build 19044 or newer, 64-bit, with WSL2 and WSLg, and the engine set up from source inside WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.5.3/docs/wsl2.md)).
- For the voice assistant: the Claude Code CLI on Windows (the `claude` command), signed in once with `claude auth login`. For the Desktop mode, Claude Desktop open with the screen unlocked.

## Known limitations

- The Desktop mode of the voice assistant types into Claude Desktop through Windows UI Automation: it takes the keyboard for about 2 seconds and clears any draft in that conversation's prompt.
- Conversations the assistant starts with **Full access, never ask (risky)** can change any file and run any command without asking. Keep the default unless you trust what you ask them to do.
- The installer is not code-signed, so SmartScreen warns on first run: choose **More info**, then **Run anyway**.
- AMD support is validated on a single card (Radeon RX 9070 XT) under WSL2, with ROCm 7.2.
- When Windows loses its microphone, WSLg audio can hang until WSL restarts. The tray app can restart WSL for you, following **Restart WSL when audio fails**.
