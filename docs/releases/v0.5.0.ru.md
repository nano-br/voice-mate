# VoiceMate 0.5.0: примечания к выпуску

В VoiceMate 0.5.0 голосовой ассистент проявляет инициативу: он сам находит нужный вам разговор, читает его, спрашивает у него, что нужно, и рассказывает вам ответ. Он также может следить за разговорами вместо вас, помнить ваши постоянные инструкции и отправлять сообщения в закрытые сессии. Теперь VoiceMate может распознавать речь через сервис распознавания, который вы запускаете сами, а справочная документация доступна на пяти языках.

## Главное

- **Ассистент проявляет инициативу:** он находит нужный вам разговор, читает его, спрашивает у него, что нужно, и рассказывает вам ответ. Вас он спрашивает только о настоящих решениях: удалить, потратить, опубликовать, вопросы вкуса. Он также читает ваше хранилище заметок всякий раз, когда заметки помогают ответить, не спрашивая заранее, а в **«Настройки»** > **«Ассистент»** предлагаются хранилища, которые Obsidian уже знает. Руководство: [docs/assistant.ru.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/assistant.ru.md).

- **Наблюдение:** скажите «следи за» разговором, и ассистент сообщает о каждом завершённом им ходе, пока вы не скажете остановиться (до 12 часов без нового хода), объединяя ходы, которые заканчиваются почти одновременно. Список **«В ожидании»** сохраняется вместе с тем, до какого места прочитан каждый транскрипт, поэтому ход, закончившийся при закрытом VoiceMate, всё равно будет сообщён, а запись с истёкшим сроком исчезает с уведомлением.

- **Постоянные инструкции:** правило, которое вы даёте ассистенту («с этого момента...»), сохраняется (до 40 правил по 300 символов) и соблюдается во всех сессиях. Добавить или удалить правило может только ответ на ваши собственные слова.

- **Закрытые сессии могут получать сообщения:** VoiceMate в фоне возобновляет закрытую сессию терминала, IDE или Remote Control в её собственной папке, и ответ возвращается как любой другой. Режим разрешений он не передаёт, если вы не задали `[assistant] resume_permission_mode` (`default`, `acceptEdits` или `plan`; `bypassPermissions` отклоняется). О недоставленном сообщении сообщается. Используемая сессия остаётся только для чтения, к ней можно обратиться через собственные инструменты сессий клиента, если они у него есть.

- **Ваш собственный сервис распознавания:** VoiceMate может распознавать речь через сервис преобразования речи в текст, который вы запускаете сами, по протоколу `voicemate-stt`, родственному протоколу провайдера голоса. Параметры движка: `--stt-engine external`, `--stt-url`, `--stt-options` и `--no-stt-fallback`. Если сервис недоступен, запись распознаёт встроенный движок, пока не указан `--no-stt-fallback`. `make stt-provider-check` проверяет сервис, а `make stt-provider-example` запускает эталонный. Подробности: [docs/stt-provider-protocol.ru.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/stt-provider-protocol.ru.md).

- **Документация на пяти языках:** архитектура, настройка, протокол провайдера распознавания, частые проблемы и использование теперь есть также на португальском, испанском, русском и упрощённом китайском, как и руководство по ассистенту и руководство по установке.

- **Меньше потерянных ответов:** когда ассистент отвечает вне модели ответа (он может потерять её, когда его разговор сжимается), VoiceMate один раз сообщает ему об этом, чтобы ответ был повторён и озвучен, а не только показан. Начало нового хода больше не озвучивает предыдущий ответ и не действует по нему.

## Требования

- Как в 0.1.0: Windows 11 или Windows 10 со сборкой 19044 или новее, 64-разрядная, с WSL2 и WSLg, а движок настроен из исходного кода внутри WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/wsl2.md)).
- Для голосового ассистента: Claude Code CLI в Windows (команда `claude`) с однократным входом через `claude auth login`. Для режима Desktop: Claude Desktop должен быть открыт, а экран не заблокирован.

## Обновление с 0.4.0

1. Обновите движок внутри WSL, в папке, куда вы клонировали VoiceMate:

   ```bash
   cd ~/voice-mate
   git pull
   make setup    # installs the new dependencies; your earlier answers are the defaults
   make doctor
   ```

2. Скачайте и проверьте установщик (шаг 2 ниже), затем запустите его. Если VoiceMate открыт, установщик сначала спросит: «VoiceMate запущен. Перед установкой программа установки закроет его вместе с движком, который он запустил. Продолжить?» Подтвердите, и он закроет VoiceMate вместе с движком и выполнит установку поверх. Ваши настройки, горячие клавиши и список **«Нескопированные»** сохраняются. Флажок «Автоматически запускать VoiceMate» предлагается только при первой установке, поэтому больше не появляется.

3. Ничего в ваших настройках и скриптах менять не нужно: ни одна настройка, опция или ключ не удалены и не переименованы, а новые необязательны. 0.5.0 это выпуск MINOR в серии 0.x, где такое возможно; здесь этого нет. У ассистента новая версия инструкций (его skill): если вы правили свою копию, VoiceMate сохранит её, а новую версию положит рядом с окончанием `.new`. Объедините их или удалите свою копию.

## Как установить (первый раз)

Установщик содержит приложение для области уведомлений. Движок распознавания работает внутри WSL2 и один раз настраивается из исходного кода; дальше приложение запускает его само.

Те же шаги со снимком каждой страницы установщика есть в [руководстве по установке](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/install-guide.ru.md).

### 1. Настройте движок в WSL2 (один раз)

1. В Windows обновите WSL: `wsl --update`. Вместе с ним устанавливается WSLg, через который WSL получает доступ к микрофону.
2. Если у вас видеокарта AMD: установите в Windows драйвер AMD Adrenalin 26.2.2 или новее, а внутри Ubuntu ROCm для WSL (ветка 7.2) по [руководству AMD](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). Команда `rocminfo` должна показать вашу видеокарту.
3. Внутри Ubuntu установите пакеты для звука и сборки:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Убедитесь, что установлены Python 3.12 и [Poetry](https://python-poetry.org/docs/#installation), склонируйте VoiceMate в домашнюю папку и запустите настройку:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detects WSL2 and the GPU, installs the matching PyTorch and the modules you pick
   make doctor   # checks microphone, audio, GPU and binaries, with a fix for each problem
   ```

   `make setup` спросит основной режим распознавания (CPU или GPU); позже его можно переключить в меню значка. Он также может предложить службу systemd, которая запускает движок вместе с WSL. С приложением VoiceMate она не нужна.

Подробности и решение проблем: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/wsl2.md).

### 2. Скачайте и проверьте установщик

Скачайте со страницы выпуска `VoiceMate-Setup-0.5.0.exe` и его файл `.sha256`. В PowerShell, в папке загрузки:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.5.0.exe -Algorithm SHA256).Hash
```

Значение должно совпасть со значением из файла `.sha256` (регистр букв не важен). Если не совпадает, не запускайте файл и скачайте его заново.

### 3. Запустите установщик

1. Откройте `VoiceMate-Setup-0.5.0.exe`. Установщик не подписан, поэтому при первом запуске SmartScreen может показать предупреждение: нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
2. Установщик запускается на языке интерфейса Windows, если он входит в эти пять; иначе он покажет диалог выбора языка на английском. VoiceMate устанавливается только для вашего пользователя, без прав администратора, в `%LOCALAPPDATA%\Programs\VoiceMate` и появляется в меню «Пуск».
3. При желании создайте ярлык на рабочем столе и включите запуск VoiceMate при входе в систему, затем завершите установку и откройте VoiceMate.

### 4. Первый запуск

1. Значок VoiceMate появляется в области уведомлений. Пока движок загружает модель (от 10 до 60 секунд), VoiceMate показывает «Запуск движка...».
2. Если появилось сообщение «Папка движка не найдена», откройте **«Настройки...»** > **«Общие»** и укажите **«Дистрибутив WSL»** и **«Папка движка»**.
3. Попробуйте диктовку: нажмите `Ctrl+Alt+V`, говорите, снова нажмите `Ctrl+Alt+V` и вставьте текст через `Ctrl+V`.
4. Если микрофон не работает, откройте **«Параметры»** Windows > **«Конфиденциальность и защита»** > **«Микрофон»** (в Windows 10 **«Конфиденциальность»**) и разрешите доступ классическим приложениям. Если звук остаётся зависшим, выберите в меню значка **«Движок»** > **«Перезапустить WSL...»** или выполните `wsl --shutdown`.

### 5. Включите голосового ассистента (по желанию)

1. Установите [Claude Code CLI](https://docs.claude.com/en/docs/claude-code) в Windows и один раз выполните `claude auth login` в терминале.
2. Нажмите кнопку **«Ассистент»** в окне состояния (или `Ctrl+Alt+W`). Пока ассистент выключен, его окно объясняет, как его включить.
3. В **«Настройки...»** > **«Ассистент»** выберите **«Режим ассистента:»**. Для **«Разговор Claude Desktop»** введите точное название этого разговора в поле **«Разговор в Desktop:»**.
4. Нажмите `Ctrl+Alt+S`, спросите "what are my conversations doing?" (что сейчас делают мои разговоры?) и снова нажмите `Ctrl+Alt+S`.

Ассистенту не нужен настроенный голос: без движка голоса он говорит голосами Windows («Настройки» > **«Ассистент»** > **«Источник голоса:»** в положении **«Автоматически»**). Чтобы говорить без горячей клавиши, нажмите **«Говорить»** в окне ассистента; во время записи кнопка превращается в **«Остановить и отправить»**.

Весь сценарий с диаграммами: [docs/usage.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/usage.md#voice-assistant).

### 6. Закрепите VoiceMate на панели задач

Windows не позволяет установщикам закреплять приложения. Откройте меню «Пуск», найдите VoiceMate, щёлкните по нему правой кнопкой мыши и выберите **«Закрепить на панели задач»**.

## Известные ограничения

- Режим Desktop голосового ассистента вводит текст в Claude Desktop через Windows UI Automation: он занимает клавиатуру примерно на 2 секунды и стирает любой черновик в поле ввода этого разговора.
- Разговоры, которые ассистент запускает с режимом **«Полный доступ, никогда не спрашивать (рискованно)»**, могут изменять любые файлы и выполнять любые команды без вопросов. Оставьте значение по умолчанию, если не доверяете тому, что поручаете им.
- Установщик не подписан, поэтому при первом запуске SmartScreen показывает предупреждение (см. шаг 3).
- Поддержка AMD проверена на одной видеокарте (Radeon RX 9070 XT) в WSL2, с ROCm 7.2.
- Когда Windows теряет микрофон, звук в WSLg может зависнуть до перезапуска WSL. Приложение может перезапустить WSL само, согласно параметру **«Перезапускать WSL при сбое звука»**.
