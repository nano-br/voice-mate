# VoiceMate 0.1.0 发行说明

我做 VoiceMate，是因为说话比打字快得多：边想边说时，你会自然地给 AI 提供远比打字时更多的上下文和细节。按下快捷键，开口说话，然后粘贴。Whisper 在本地运行，你的声音不会离开你的电脑。从 2026 年 3 月起，我每个工作日都在用它：起初是在装有 NVIDIA 显卡的 Windows 上，换成 AMD 显卡后改在 WSL2 中使用，所以这条路径在本版本中是新加入的，目前仍属实验性。

这是第一个公开版本。

## 亮点

- **听写到剪贴板**：`Ctrl+Alt+V` 开始和停止录音，本地 Whisper 完成转写，文字随即可以粘贴到任何应用或 AI 工具中。
- **Windows 托盘应用（新）**：VoiceMate 现在常驻系统托盘。它在 WSL2 中启动并监管语音引擎，负责快捷键和提示音，并确认每条转写结果确实进入了剪贴板。没有复制成功的内容会保留在 **未复制** 列表中，重启后也不会丢失。
- **按用户安装的安装程序**：`VoiceMate-Setup-0.1.0.exe` 无需管理员权限即可安装，并可选择在登录时启动 VoiceMate。
- **Linux、WSL2 和 AMD 显卡（实验性）**：`make setup` 会检测 NVIDIA、AMD 或 CPU，并安装匹配的 PyTorch；在 AMD 上，分层的语音识别链会选用可用的最佳后端。
- **五种语言**：应用、安装程序和 README 提供 English、Português (Brasil)、Español、Русский 和 简体中文 版本。
- **听写语言**：在 **设置...** > **常规** > **听写语言** 中选择你说话的语言：**与界面相同**（默认）、**自动检测** 或九种语言之一。对 VoiceMate 自己启动的引擎，除 **自动检测** 外，它同时决定 Claude 语音回答所用的语言。
- **与 Claude 语音对话（实验性）**：`Ctrl+Alt+A` 会把你说的话发送给 Claude，并朗读回答（Kokoro 或 OmniVoice，在 `make setup` 中选择；VoxCPM2 可作为可选扩展安装）。
- **`make doctor`**：检查麦克风、音频、GPU、whisper.cpp 和 Claude CLI，并针对发现的每个问题给出修复方法。

## 系统要求

- Windows 11，或 Windows 10 内部版本 19044 或更高，64 位，并安装 WSL2 和 WSLg；文档中介绍的配置使用 Windows 11 上的 Ubuntu。安装程序本身可在 Windows 10 1809 或更高版本上运行，但引擎需要 WSL2（Windows 10 1903 或更高版本）和 WSLg（Windows 10 内部版本 19044 或更高，或 Windows 11）。
- WSL 中需要：Python 3.12、Poetry、git 和 make，以及下文列出的软件包。
- 强烈建议使用 GPU。WSL2 路径已在 AMD Radeon RX 9070 XT 上验证，使用 WSL 版 ROCm 7.2 和 AMD Adrenalin 26.2.2 或更高版本的驱动；`make setup` 也支持 NVIDIA（CUDA）和 CPU，但它们尚未在 WSL2 上测试过。
- 仅用于与 Claude 对话：Node.js 18 或更高版本，以及在 WSL 中安装并已登录的 Claude Code CLI。

## 安装步骤

安装程序只包含托盘应用。语音引擎运行在 WSL2 中，需要从源码配置一次；之后由托盘应用替你启动。

### 1. 在 WSL2 中配置引擎（只需一次）

1. 在 Windows 中更新 WSL：`wsl --update`。WSLg 会随之安装，它让 WSL 能使用你的麦克风。
2. 如果使用 AMD 显卡：在 Windows 中安装 AMD Adrenalin 26.2.2 或更高版本的驱动，并按照 [AMD 官方指南](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html) 在 Ubuntu 中安装 WSL 版 ROCm（7.2 版本线）。`rocminfo` 应能列出你的 GPU。
3. 在 Ubuntu 中安装音频和编译所需的软件包：

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. 确认已安装 Python 3.12 和 [Poetry](https://python-poetry.org/docs/#installation)，然后把 VoiceMate 克隆到你的主目录并运行配置：

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # 检测 WSL2 和 GPU，安装匹配的 PyTorch 以及你选择的模块
   make doctor   # 检查麦克风、音频、GPU 和二进制文件，并给出每个问题的修复方法
   ```

   当 `make setup` 询问主要流程时，默认的 `claude_chat` 会安装语音对话所需的 Claude 和语音合成模块；只需要听写的话，请选择 `clipboard`。

   `make setup` 可能会提议安装一个随 WSL 启动引擎的 systemd 服务。使用托盘应用时不需要它。

5. 可选，用于与 Claude 对话：在 WSL 中安装 Node.js 18 或更高版本和 Claude Code CLI（`npm install -g @anthropic-ai/claude-code`），然后运行一次 `claude` 完成登录。

更多细节和故障排查：[docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.1.0/docs/wsl2.md)。

### 2. 下载并校验安装程序

从发布页面下载 `VoiceMate-Setup-0.1.0.exe` 及其 `.sha256` 文件。在下载目录中打开 PowerShell，运行：

```powershell
(Get-FileHash .\VoiceMate-Setup-0.1.0.exe -Algorithm SHA256).Hash
```

输出的值必须与 `.sha256` 文件中的值一致（不区分大小写）。如果不一致，请不要运行该文件，并重新下载。

### 3. 运行安装程序

1. 打开 `VoiceMate-Setup-0.1.0.exe`。安装程序没有代码签名，因此首次运行时 Windows SmartScreen 可能会发出警告：点击 **更多信息**，然后点击 **仍要运行**。
2. 如果 Windows 的显示语言是这五种之一，安装程序会直接使用该语言；否则会请你选择一种语言（列表中英语排在第一位）。VoiceMate 只为当前用户安装，无需管理员权限，安装位置为 `%LOCALAPPDATA%\Programs\VoiceMate`，并会添加到“开始”菜单。
3. 可以按需创建桌面快捷方式，并让 VoiceMate 在登录时启动；然后完成安装并打开 VoiceMate。

### 4. 首次运行

1. VoiceMate 图标会出现在托盘中。引擎加载模型期间（10 到 60 秒），VoiceMate 会显示“正在启动引擎...”。
2. 托盘应用会在默认的 WSL 发行版中，到 `~/voice-mate`、`~/workspace/voice-mate` 等常见目录查找引擎。如果显示“未找到引擎文件夹”，请打开 **设置...** > **常规**，填写 **WSL 发行版** 和 **引擎文件夹**。
3. 如果已有 systemd 服务在运行引擎，托盘应用会连接到它，而不会再启动一个。托盘应用仅连接、而非由它启动的引擎（上述服务，或你手动启动的引擎）会沿用它自己的语言参数，**听写语言** 对它不起作用。
4. 如果 VoiceMate 弹出“快捷键不可用”通知，或在 **设置...** > **快捷键** 中某个快捷键显示“已被其他应用占用”，说明旧的快捷键脚本（PowerShell 或 AutoHotkey）仍在运行：关闭它，并从 `shell:startup` 中删除它的快捷方式。
5. 试一试：按 `Ctrl+Alt+V`，说话，再按一次 `Ctrl+Alt+V`，然后用 `Ctrl+V` 粘贴。如果配置了 Claude，`Ctrl+Alt+A` 会开始与 Claude 对话。
6. 如果麦克风无法使用，请打开 Windows **设置** > **隐私和安全性** > **麦克风**（Windows 10 中为 **隐私**），允许桌面应用使用麦克风。如果音频仍然卡住，请使用托盘菜单 > **引擎** > **重启 WSL...**，或运行 `wsl --shutdown`。

### 5. 固定到任务栏

Windows 不允许安装程序固定应用，因此首次运行时会显示 **将 VoiceMate 固定到任务栏** 通知。打开“开始”菜单，搜索 VoiceMate，右键单击它并选择 **固定到任务栏**。

### 6. 修改快捷键、声音和其他设置

打开托盘图标菜单 > **设置...**：

- **快捷键**：修改听写和 Claude 的快捷键。
- **声音**：内置声音或你自己的 WAV 文件，以及音量。
- **常规**：**语言**、**听写语言**（默认 **与界面相同**；除 **自动检测** 外，它同时决定 Claude 语音回答的语言，并会重启引擎）、通知、**登录时启动 VoiceMate**、**始终在任务栏上显示 VoiceMate 图标**、引擎（**WSL 发行版**、**引擎文件夹**）以及 **音频故障时重启 WSL**（**自动**、**先询问** 或 **从不**）。

要退出，请在托盘图标菜单中选择 **退出 VoiceMate**。

## 已知限制

- Linux、WSL2 和 AMD 支持仍是**实验性**的：目前只在一块 AMD 显卡（Radeon RX 9070 XT）上于 WSL2 中验证过。NVIDIA 在 WSL2 上尚未测试。
- 安装程序没有代码签名，因此首次运行时 SmartScreen 会发出警告（见第 3 步）。
- 在 Windows 上，托盘应用管理的是 WSL2 中的引擎。让托盘应用管理直接在 Windows 上原生运行的引擎，计划在后续版本中支持。
- 在 WSL2 中，whisper.cpp 的 Vulkan 无法使用 GPU（那里的 Vulkan 是软件渲染器），因此 AMD 上的转写走的是基于 ROCm 的 openai-whisper。更快的 CTranslate2-ROCm 路径是可选方案，需要自行完成一次耗时且占用资源的编译。
- Windows 丢失麦克风后，WSLg 的音频可能会卡住，直到 WSL 重启。托盘应用可以按照 **音频故障时重启 WSL** 的设置替你重启 WSL。
- 与 Claude 的语音对话是实验性功能，需要已登录的 Claude Code CLI。
