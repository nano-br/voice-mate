# VoiceMate 0.1.0: notas da versão

Criei o VoiceMate porque falar é muito mais rápido do que digitar: quando você pensa em voz alta, dá à IA muito mais contexto e detalhe do que jamais digitaria. Aperte um atalho, fale, cole. O Whisper roda localmente, então a sua voz nunca sai da sua máquina. Uso o VoiceMate todos os dias úteis desde março de 2026, primeiro no Windows com uma placa NVIDIA e, depois de trocar por uma placa AMD, no WSL2. Por isso esse caminho é novo aqui e ainda experimental.

Esta é a primeira versão pública.

## Destaques

- **Ditado para a área de transferência:** `Ctrl+Alt+V` inicia e para a gravação, o Whisper local transcreve e o texto fica pronto para colar em qualquer aplicativo ou ferramenta de IA.
- **Aplicativo de bandeja para Windows (novo):** o VoiceMate agora fica na bandeja do sistema. Ele inicia e supervisiona o motor de fala dentro do WSL2, registra os atalhos, toca os sons de aviso e confere se cada transcrição chegou mesmo à área de transferência. O que não chegou fica em **Não copiadas**, mesmo depois de reiniciar.
- **Instalador por usuário:** o `VoiceMate-Setup-0.1.0.exe` instala sem pedir permissão de administrador e oferece iniciar o VoiceMate quando você fizer login.
- **Linux, WSL2 e GPUs AMD (experimental):** o `make setup` detecta NVIDIA, AMD ou CPU e instala o PyTorch certo; na AMD, uma cadeia de reconhecimento de fala em camadas escolhe o melhor backend que funcionar.
- **Cinco idiomas:** aplicativo, instalador e README em English, Português (Brasil), Español, Русский e 简体中文.
- **Idioma do ditado:** escolha em que idioma você fala em **Configurações...** > **Geral** > **Idioma do ditado**: **Igual ao da interface** (padrão), **Detectar automaticamente** ou um dos nove idiomas. Para o motor que o VoiceMate inicia, ele também define o idioma das respostas faladas do Claude, exceto com **Detectar automaticamente**.
- **Conversa por voz com o Claude (experimental):** `Ctrl+Alt+A` envia o que você fala ao Claude e lê a resposta em voz alta (Kokoro ou OmniVoice, à escolha no `make setup`; o VoxCPM2 está disponível como extra opcional).
- **`make doctor`:** verifica microfone, áudio, GPU, whisper.cpp e o CLI do Claude, e mostra como corrigir cada problema encontrado.

## Requisitos

- Windows 11 ou Windows 10 build 19044 ou mais recente, 64 bits, com WSL2 e WSLg; a configuração documentada usa Ubuntu no Windows 11. O instalador em si roda no Windows 10 1809 ou mais recente, mas o motor precisa do WSL2 (Windows 10 1903 ou mais recente) e do WSLg (Windows 10 build 19044 ou mais recente, ou Windows 11).
- Dentro do WSL: Python 3.12, Poetry, git e make, além dos pacotes listados abaixo.
- É muito recomendável ter uma GPU. O uso com WSL2 foi validado com uma AMD Radeon RX 9070 XT, ROCm 7.2 para WSL e o driver AMD Adrenalin 26.2.2 ou mais recente; o `make setup` também oferece NVIDIA (CUDA) e CPU, mas essas opções não foram testadas no WSL2.
- Só para a conversa com o Claude: Node.js 18 ou mais recente e o Claude Code CLI, instalado e autenticado dentro do WSL.

## Como instalar

O instalador traz o aplicativo de bandeja. O motor de fala roda dentro do WSL2 e é configurado uma vez a partir do código-fonte; depois disso o aplicativo de bandeja o inicia para você.

### 1. Configure o motor no WSL2 (uma vez)

1. No Windows, atualize o WSL: `wsl --update`. O WSLg, que dá ao WSL acesso ao seu microfone, vem junto.
2. Com GPU AMD: instale no Windows o driver AMD Adrenalin 26.2.2 ou mais recente e, dentro do Ubuntu, o ROCm para WSL (trilha 7.2), seguindo o [guia da AMD](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). O `rocminfo` precisa listar a sua GPU.
3. Dentro do Ubuntu, instale os pacotes de áudio e de compilação:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Confira se o Python 3.12 e o [Poetry](https://python-poetry.org/docs/#installation) estão instalados, clone o VoiceMate na sua pasta pessoal e rode a configuração:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detecta o WSL2 e a GPU, instala o PyTorch certo e os módulos que você escolher
   make doctor   # confere microfone, áudio, GPU e binários, com a correção de cada problema
   ```

   Quando o `make setup` perguntar o fluxo principal, `claude_chat` (o padrão) instala os módulos do Claude e de texto para fala usados na conversa por voz; escolha `clipboard` se quiser só o ditado.

   O `make setup` pode oferecer um serviço do systemd que inicia o motor junto com o WSL. Com o aplicativo de bandeja ele não é necessário.

5. Opcional, para a conversa com o Claude: instale o Node.js 18 ou mais recente e o Claude Code CLI dentro do WSL (`npm install -g @anthropic-ai/claude-code`) e rode `claude` uma vez para fazer login.

Mais detalhes e solução de problemas: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.1.0/docs/wsl2.md).

### 2. Baixe e confira o instalador

Baixe o `VoiceMate-Setup-0.1.0.exe` e o arquivo `.sha256` dele na página da versão. No PowerShell, na pasta do download:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.1.0.exe -Algorithm SHA256).Hash
```

O valor precisa ser igual ao do arquivo `.sha256` (maiúsculas e minúsculas não importam). Se não for, não execute o arquivo e baixe de novo.

### 3. Execute o instalador

1. Abra o `VoiceMate-Setup-0.1.0.exe`. O instalador não tem assinatura de código, então o SmartScreen do Windows pode alertar na primeira execução: escolha **Mais informações** e depois **Executar assim mesmo**.
2. O instalador abre no idioma de exibição do Windows quando ele é um dos cinco; caso contrário, pede que você escolha um (o inglês é o primeiro da lista). O VoiceMate é instalado só para o seu usuário, sem pedir permissão de administrador, em `%LOCALAPPDATA%\Programs\VoiceMate`, e aparece no menu Iniciar.
3. Se quiser, crie um atalho na área de trabalho e deixe o VoiceMate iniciar com o login; depois conclua e abra o VoiceMate.

### 4. Primeira execução

1. O ícone do VoiceMate aparece na bandeja. Enquanto o motor carrega o modelo (de 10 a 60 segundos), o VoiceMate mostra "Iniciando o motor...".
2. O aplicativo procura o motor na distro padrão do WSL, em pastas comuns como `~/voice-mate` ou `~/workspace/voice-mate`. Se aparecer "Pasta do motor não encontrada", abra **Configurações...** > **Geral** e preencha **Distro do WSL** e **Pasta do motor**.
3. Se um serviço do systemd já roda o motor, o aplicativo se conecta a ele em vez de iniciar outro. Um motor ao qual o aplicativo apenas se conecta (esse ou um que você iniciou à mão) mantém os próprios parâmetros de idioma, então o **Idioma do ditado** não o altera.
4. Se o VoiceMate mostrar a notificação "Atalho indisponível", ou se um atalho mostrar "Em uso por outro aplicativo" em **Configurações...** > **Atalhos**, um script antigo de atalhos (PowerShell ou AutoHotkey) ainda está rodando: feche-o e remova o atalho dele do `shell:startup`.
5. Teste: aperte `Ctrl+Alt+V`, fale, aperte `Ctrl+Alt+V` de novo e cole com `Ctrl+V`. `Ctrl+Alt+A` inicia a conversa com o Claude, se você a configurou.
6. Se o microfone não funcionar, abra **Configurações** do Windows > **Privacidade e segurança** > **Microfone** (**Privacidade** no Windows 10) e permita que os aplicativos para desktop o usem. Se o áudio continuar travado, use o menu da bandeja > **Motor** > **Reiniciar o WSL...** ou rode `wsl --shutdown`.

### 5. Fixe na barra de tarefas

O Windows não deixa instaladores fixarem aplicativos, por isso a primeira execução mostra a notificação **Fixe o VoiceMate na barra de tarefas**. Abra o Iniciar, pesquise VoiceMate, clique nele com o botão direito e escolha **Fixar na barra de tarefas**.

### 6. Mude atalhos, sons e outras opções

Abra o menu do ícone da bandeja > **Configurações...**:

- **Atalhos**: troque os atalhos do ditado e do Claude.
- **Sons**: sons embutidos ou arquivos WAV seus, e o volume.
- **Geral**: **Idioma**, **Idioma do ditado** (padrão **Igual ao da interface**; ele também define o idioma das respostas faladas do Claude, exceto com **Detectar automaticamente**, e reinicia o motor), notificações, **Iniciar o VoiceMate ao fazer login**, **Sempre mostrar o ícone do VoiceMate na barra de tarefas**, o motor (**Distro do WSL**, **Pasta do motor**) e **Reiniciar o WSL se o áudio falhar** (**Automaticamente**, **Perguntar antes** ou **Nunca**).

Para sair, use o menu do ícone da bandeja > **Sair do VoiceMate**.

## Limitações conhecidas

- O suporte a Linux, WSL2 e AMD é **experimental**: foi validado com uma única placa AMD (Radeon RX 9070 XT) no WSL2. A NVIDIA no WSL2 não foi testada.
- O instalador não tem assinatura de código, então o SmartScreen alerta na primeira execução (veja o passo 3).
- No Windows, o aplicativo de bandeja controla um motor dentro do WSL2. Rodar o motor nativamente no Windows com o aplicativo de bandeja fica para uma versão futura.
- No WSL2, o whisper.cpp com Vulkan não usa a GPU (o Vulkan ali é um renderizador por software), então a transcrição na AMD passa pelo openai-whisper sobre ROCm. O caminho mais rápido, CTranslate2-ROCm, é uma compilação pesada e opcional.
- Quando o Windows perde o microfone, o áudio do WSLg pode travar até o WSL reiniciar. O aplicativo pode reiniciar o WSL para você, conforme **Reiniciar o WSL se o áudio falhar**.
- A conversa por voz com o Claude é experimental e precisa do Claude Code CLI autenticado.
