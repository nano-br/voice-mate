# VoiceMate 0.2.0: notas da versão

O VoiceMate 0.2.0 traz uma assistente de voz que acompanha as suas outras conversas do Claude, deixa você escolher onde a transcrição roda (CPU ou GPU) e abre a saída de voz para qualquer serviço de texto para fala, por meio de um pequeno protocolo HTTP. O ditado para a área de transferência continua como antes.

## Destaques

- **Assistente de voz (experimental, desativada por padrão):** uma conversa do Claude, a central, com a qual você fala usando `Ctrl+Alt+S` ou digita na janela dela (`Ctrl+Alt+W`, ou o novo botão **Assistente** da janela de status). Ela lista e lê as suas outras conversas do Claude, faz perguntas a elas, inicia novas em segundo plano e avisa quando respondem. São dois modos: **Conversa própria do VoiceMate** (um processo do Claude Code que o VoiceMate controla, também exibido no Claude Desktop e no celular pelo Remote Control) ou **Uma conversa do Claude Desktop** que você já tenha.
- **Respostas de outras conversas:** faladas assim que chegam, ou guardadas numa caixa de entrada com um aviso curto, um som ou nada. `Ctrl+Alt+R` (**Ouvir o que está pronto**) dá um resumo falado de tudo o que está esperando, e um selo azul no ícone da bandeja mostra a quantidade.
- **Modo direto e comandos de voz** em inglês, português e espanhol: "falar direto com a conversa X" envia suas palavras do jeito que estão para essa conversa; "voltar para a assistente", "ler a última resposta", "parar de falar" e outros funcionam sem nenhuma IA.
- **Configurações por voz:** peça à assistente para mudar a entrega das respostas, o modelo, a voz e cerca de vinte outras configurações.
- **Transcrição na CPU ou na GPU:** troque pelo menu da bandeja (**Transcrição**) ou pela janela de configurações. A CPU (faster-whisper int8 com VAD) deixa a GPU livre para outros trabalhos; a GPU é a mais rápida. Um modo que não está instalado é instalado depois de perguntar, com o tamanho do download.
- **Provedor de voz personalizado:** a nova aba **Voz** conecta o motor a qualquer serviço de texto para fala que siga o protocolo `voicemate-tts` ([docs/tts-provider-protocol.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/tts-provider-protocol.md)), com um seletor de voz carregado do provedor e um botão **Testar voz**. As respostas da assistente são faladas frase a frase por ele, ou pelo Kokoro.
- **Gravação mais estável:** uma abertura do microfone que o sistema de áudio recusa é tentada de novo automaticamente antes de aparecer "Microfone indisponível".

## Requisitos

- Como no 0.1.0: Windows 11, ou Windows 10 build 19044 ou mais recente, 64 bits, com WSL2 e WSLg, e o motor configurado a partir do código-fonte dentro do WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/wsl2.md)).
- Para a assistente de voz: o Claude Code CLI no Windows (o comando `claude`), com login feito uma vez por `claude auth login`. Para o modo Desktop, o Claude Desktop aberto e a tela desbloqueada.

## Atualizando a partir do 0.1.0

1. Atualize o motor dentro do WSL, na pasta onde você clonou o VoiceMate:

   ```bash
   cd ~/voice-mate
   git pull
   make setup    # installs the new dependencies; it asks for the default transcription mode
   make doctor
   ```

   O novo aplicativo de bandeja precisa desse motor para os modos de transcrição e para as respostas faladas. Com um motor antigo, o ditado continua funcionando, mas as respostas ficam só em texto.

2. Baixe e confira o instalador (passo 2 abaixo) e depois execute-o. Ele substitui o 0.1.0 no lugar e mantém as suas configurações, os atalhos e a lista **Não copiadas**. Feche o VoiceMate antes, se o instalador pedir.

## Como instalar (primeira vez)

O instalador traz o aplicativo de bandeja. O motor de fala roda dentro do WSL2 e é configurado uma vez a partir do código-fonte; depois disso o aplicativo de bandeja o inicia para você.

### 1. Configure o motor no WSL2 (uma vez)

1. No Windows, atualize o WSL: `wsl --update`. O WSLg, que dá ao WSL acesso ao seu microfone, vem junto.
2. Com GPU AMD: instale no Windows o driver AMD Adrenalin 26.2.2 ou mais recente e, dentro do Ubuntu, o ROCm para WSL (trilha 7.2), seguindo o [guia da AMD](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). O `rocminfo` precisa listar a sua GPU.
3. Dentro do Ubuntu, instale os pacotes de áudio e de compilação:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Confira se o Python 3.12 e o [Poetry](https://python-poetry.org/docs/#installation) estão instalados, clone o VoiceMate na sua pasta pessoal e rode a configuração:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detects WSL2 and the GPU, installs the matching PyTorch and the modules you pick
   make doctor   # checks microphone, audio, GPU and binaries, with a fix for each problem
   ```

   O `make setup` pergunta o modo de transcrição padrão (CPU ou GPU); você pode trocar depois pelo menu da bandeja. Ele também pode oferecer um serviço do systemd que inicia o motor junto com o WSL. Com o aplicativo de bandeja ele não é necessário.

Mais detalhes e solução de problemas: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/wsl2.md).

### 2. Baixe e confira o instalador

Baixe o `VoiceMate-Setup-0.2.0.exe` e o arquivo `.sha256` dele na página da versão. No PowerShell, na pasta do download:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.2.0.exe -Algorithm SHA256).Hash
```

O valor precisa ser igual ao do arquivo `.sha256` (maiúsculas e minúsculas não importam). Se não for, não execute o arquivo e baixe de novo.

### 3. Execute o instalador

1. Abra o `VoiceMate-Setup-0.2.0.exe`. O instalador não tem assinatura de código, então o SmartScreen do Windows pode alertar na primeira execução: escolha **Mais informações** e depois **Executar assim mesmo**.
2. O instalador abre no idioma de exibição do Windows quando ele é um dos cinco; caso contrário, pede que você escolha um. O VoiceMate é instalado só para o seu usuário, sem pedir permissão de administrador, em `%LOCALAPPDATA%\Programs\VoiceMate`, e aparece no menu Iniciar.
3. Se quiser, crie um atalho na área de trabalho e deixe o VoiceMate iniciar com o login; depois conclua e abra o VoiceMate.

### 4. Primeira execução

1. O ícone do VoiceMate aparece na bandeja. Enquanto o motor carrega o modelo (de 10 a 60 segundos), o VoiceMate mostra "Iniciando o motor...".
2. Se aparecer "Pasta do motor não encontrada", abra **Configurações...** > **Geral** e preencha **Distro do WSL** e **Pasta do motor**.
3. Teste o ditado: aperte `Ctrl+Alt+V`, fale, aperte `Ctrl+Alt+V` de novo e cole com `Ctrl+V`.
4. Se o microfone não funcionar, abra **Configurações** do Windows > **Privacidade e segurança** > **Microfone** (**Privacidade** no Windows 10) e permita que os aplicativos para desktop o usem. Se o áudio continuar travado, use o menu da bandeja > **Motor** > **Reiniciar o WSL...** ou rode `wsl --shutdown`.

### 5. Ative a assistente de voz (opcional)

1. Instale o [Claude Code CLI](https://docs.claude.com/en/docs/claude-code) no Windows e rode `claude auth login` uma vez num terminal.
2. Aperte o botão **Assistente** na janela de status (ou `Ctrl+Alt+W`). Enquanto a assistente está desativada, a janela dela explica como ativá-la.
3. Em **Configurações...** > **Assistente**, escolha o **Modo da assistente:**. Para **Uma conversa do Claude Desktop**, digite o título exato dessa conversa em **Conversa do Desktop:**.
4. Aperte `Ctrl+Alt+S`, pergunte "o que as minhas conversas estão fazendo?" e aperte `Ctrl+Alt+S` de novo.

O fluxo completo, com diagramas: [docs/usage.md](https://github.com/nano-br/voice-mate/blob/v0.2.0/docs/usage.md#voice-assistant-experimental).

### 6. Fixe na barra de tarefas

O Windows não deixa instaladores fixarem aplicativos. Abra o Iniciar, pesquise VoiceMate, clique nele com o botão direito e escolha **Fixar na barra de tarefas**.

## Limitações conhecidas

- A assistente de voz é **experimental**. O modo Desktop digita no Claude Desktop pela Automação da Interface do Windows (UI Automation): ele toma conta do teclado por cerca de 2 segundos e apaga qualquer rascunho no campo de texto dessa conversa.
- As conversas que a assistente inicia com **Acesso total, nunca perguntar (arriscado)** podem alterar qualquer arquivo e executar qualquer comando sem perguntar. Mantenha o padrão, a menos que você confie no que pede a elas.
- O instalador não tem assinatura de código, então o SmartScreen alerta na primeira execução (veja o passo 3).
- O suporte a Linux, WSL2 e AMD continua **experimental**: foi validado com uma única placa AMD (Radeon RX 9070 XT) no WSL2.
- Quando o Windows perde o microfone, o áudio do WSLg pode travar até o WSL reiniciar. O aplicativo de bandeja pode reiniciar o WSL para você, conforme **Reiniciar o WSL se o áudio falhar**.
