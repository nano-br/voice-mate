# VoiceMate 0.1.0: примечания к выпуску

VoiceMate появился из простой мысли: говорить намного быстрее, чем печатать, а когда думаешь вслух, даёшь ИИ гораздо больше контекста и деталей, чем при наборе текста. Нажмите горячую клавишу, скажите, что нужно, и вставьте текст. Whisper работает локально, так что ваш голос не покидает компьютер. Я пользуюсь VoiceMate каждый рабочий день с марта 2026 года: сначала в Windows с видеокартой NVIDIA, а после перехода на видеокарту AMD в WSL2. Поэтому этот путь здесь новый и пока экспериментальный.

Это первый публичный выпуск.

## Главное

- **Диктовка в буфер обмена:** `Ctrl+Alt+V` начинает и останавливает запись, локальный Whisper распознаёт речь, и текст сразу можно вставить в любое приложение или инструмент ИИ.
- **Приложение для области уведомлений Windows (новое):** теперь VoiceMate работает из области уведомлений. Оно запускает движок распознавания внутри WSL2 и следит за ним, регистрирует горячие клавиши, воспроизводит звуковые сигналы и проверяет, что каждая расшифровка действительно попала в буфер обмена. Всё, что не попало, остаётся в списке **«Нескопированные»**, даже после перезапуска.
- **Установщик для текущего пользователя:** `VoiceMate-Setup-0.1.0.exe` ставится без запроса прав администратора и предлагает запускать VoiceMate при входе в систему.
- **Linux, WSL2 и видеокарты AMD (экспериментально):** `make setup` определяет NVIDIA, AMD или CPU и ставит подходящую сборку PyTorch; на AMD многоуровневая цепочка распознавания речи выбирает лучший из работающих бэкендов.
- **Пять языков:** приложение, установщик и README на языках English, Português (Brasil), Español, Русский и 简体中文.
- **Язык диктовки:** выберите язык, на котором вы говорите, в **«Настройки...»** > **«Общие»** > **«Язык диктовки»**: **«Как в интерфейсе»** (по умолчанию), **«Определять автоматически»** или один из девяти языков. Он же задаёт язык устных ответов Claude.
- **Голосовой разговор с Claude (экспериментально):** `Ctrl+Alt+A` отправляет сказанное в Claude и зачитывает ответ вслух (Kokoro или OmniVoice, выбор в `make setup`; VoxCPM2 доступен как необязательный дополнительный пакет).
- **`make doctor`:** проверяет микрофон, звук, видеокарту, whisper.cpp и Claude CLI и подсказывает, как исправить каждую найденную проблему.

## Требования

- Windows 11 или Windows 10 со сборкой 19044 или новее, 64-разрядная, с WSL2 и WSLg; в документации описана настройка Ubuntu в Windows 11. Сам установщик работает в Windows 10 1809 и новее, но для движка нужны WSL2 (Windows 10 1903 или новее) и WSLg (Windows 10 со сборкой 19044 или новее либо Windows 11).
- Внутри WSL: Python 3.12, Poetry, git и make, а также пакеты, перечисленные ниже.
- Видеокарта очень желательна. Путь через WSL2 проверен на AMD Radeon RX 9070 XT с ROCm 7.2 для WSL и драйвером AMD Adrenalin 26.2.2 или новее; `make setup` также предлагает NVIDIA (CUDA) и CPU, но в WSL2 они не проверялись.
- Только для разговора с Claude: Node.js 18 или новее и Claude Code CLI, установленный внутри WSL, с выполненным входом.

## Как установить

Установщик содержит приложение для области уведомлений. Движок распознавания работает внутри WSL2 и один раз настраивается из исходного кода; дальше приложение запускает его само.

### 1. Настройте движок в WSL2 (один раз)

1. В Windows обновите WSL: `wsl --update`. Вместе с ним устанавливается WSLg, через который WSL получает доступ к микрофону.
2. Если у вас видеокарта AMD: установите в Windows драйвер AMD Adrenalin 26.2.2 или новее, а внутри Ubuntu ROCm для WSL (ветка 7.2) по [руководству AMD](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). Команда `rocminfo` должна показать вашу видеокарту.
3. Внутри Ubuntu установите пакеты для звука и сборки:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Убедитесь, что установлены Python 3.12 и [Poetry](https://python-poetry.org/docs/#installation), склонируйте VoiceMate в домашнюю папку и запустите настройку:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # определяет WSL2 и видеокарту, ставит подходящий PyTorch и выбранные модули
   make doctor   # проверяет микрофон, звук, видеокарту и бинарные файлы и подсказывает исправления
   ```

   Когда `make setup` спросит про основной сценарий, `claude_chat` (по умолчанию) устанавливает модули Claude и синтеза речи для голосового разговора; если нужна только диктовка, выберите `clipboard`.

   `make setup` может предложить службу systemd, которая запускает движок вместе с WSL. С приложением для области уведомлений она не нужна.

5. По желанию, для разговора с Claude: установите внутри WSL Node.js 18 или новее и Claude Code CLI (`npm install -g @anthropic-ai/claude-code`), затем один раз запустите `claude`, чтобы войти.

Подробности и решение проблем: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.1.0/docs/wsl2.md).

### 2. Скачайте и проверьте установщик

Скачайте со страницы выпуска `VoiceMate-Setup-0.1.0.exe` и его файл `.sha256`. В PowerShell, в папке загрузки:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.1.0.exe -Algorithm SHA256).Hash
```

Значение должно совпасть со значением из файла `.sha256` (регистр букв не важен). Если не совпадает, не запускайте файл и скачайте его заново.

### 3. Запустите установщик

1. Откройте `VoiceMate-Setup-0.1.0.exe`. Установщик не подписан, поэтому при первом запуске SmartScreen может показать предупреждение: нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
2. Установщик запускается на языке интерфейса Windows, если он входит в эти пять; иначе он предложит выбрать язык (английский стоит первым в списке). VoiceMate устанавливается только для вашего пользователя, без прав администратора, в `%LOCALAPPDATA%\Programs\VoiceMate` и появляется в меню «Пуск».
3. При желании создайте ярлык на рабочем столе и включите запуск VoiceMate при входе в систему, затем завершите установку и откройте VoiceMate.

### 4. Первый запуск

1. Значок VoiceMate появляется в области уведомлений. Пока движок загружает модель (от 10 до 60 секунд), VoiceMate показывает «Запуск движка...».
2. Приложение ищет движок в дистрибутиве WSL по умолчанию, в обычных папках вроде `~/voice-mate` или `~/workspace/voice-mate`. Если появилось сообщение «Папка движка не найдена», откройте **«Настройки...»** > **«Общие»** и укажите **«Дистрибутив WSL»** и **«Папка движка»**.
3. Если движок уже запущен службой systemd, приложение подключается к нему и не запускает второй.
4. Если VoiceMate показывает уведомление «Горячая клавиша недоступна» или у горячей клавиши в **«Настройки...»** > **«Горячие клавиши»** написано «Занято другим приложением», всё ещё работает старый скрипт горячих клавиш (PowerShell или AutoHotkey): закройте его и удалите его ярлык из `shell:startup`.
5. Попробуйте: нажмите `Ctrl+Alt+V`, говорите, снова нажмите `Ctrl+Alt+V` и вставьте текст через `Ctrl+V`. `Ctrl+Alt+A` начинает разговор с Claude, если вы его настроили.
6. Если микрофон не работает, откройте **«Параметры»** Windows > **«Конфиденциальность и защита»** > **«Микрофон»** (в Windows 10 **«Конфиденциальность»**) и разрешите доступ классическим приложениям. Если звук остаётся зависшим, выберите **«Перезапустить WSL...»** в меню значка или выполните `wsl --shutdown`.

### 5. Закрепите VoiceMate на панели задач

Windows не позволяет установщикам закреплять приложения, поэтому при первом запуске появляется уведомление **«Закрепите VoiceMate на панели задач»**. Откройте меню «Пуск», найдите VoiceMate, щёлкните по нему правой кнопкой мыши и выберите **«Закрепить на панели задач»**.

### 6. Горячие клавиши, звуки и другие настройки

Откройте меню значка в области уведомлений > **«Настройки...»**:

- **«Горячие клавиши»**: сочетания для диктовки и для Claude.
- **«Звуки»**: встроенные звуки или свои WAV-файлы и громкость.
- **«Общие»**: **«Язык»**, **«Язык диктовки»** (по умолчанию **«Как в интерфейсе»**; он же задаёт язык устных ответов Claude и перезапускает движок), уведомления, **«Запускать VoiceMate при входе в систему»**, **«Всегда показывать значок VoiceMate на панели задач»**, движок (**«Дистрибутив WSL»**, **«Папка движка»**) и **«Перезапускать WSL при сбое звука»** (**«Автоматически»**, **«Сначала спрашивать»** или **«Никогда»**).

Чтобы выйти, выберите в меню значка **«Выйти из VoiceMate»**.

## Известные ограничения

- Поддержка Linux, WSL2 и AMD **экспериментальная**: она проверена на одной видеокарте AMD (Radeon RX 9070 XT) в WSL2. NVIDIA в WSL2 не проверялась.
- Установщик не подписан, поэтому при первом запуске SmartScreen показывает предупреждение (см. шаг 3).
- В Windows приложение управляет движком внутри WSL2. Запуск движка прямо в Windows под управлением приложения запланирован в одном из следующих выпусков.
- В WSL2 whisper.cpp с Vulkan не может использовать видеокарту (Vulkan там программный), поэтому на AMD распознавание идёт через openai-whisper на ROCm. Более быстрый путь через CTranslate2-ROCm требует тяжёлой сборки и включается по желанию.
- Когда Windows теряет микрофон, звук в WSLg может зависнуть до перезапуска WSL. Приложение может перезапустить WSL само, согласно параметру **«Перезапускать WSL при сбое звука»**.
- Голосовой разговор с Claude экспериментальный и требует Claude Code CLI с выполненным входом.
