# VoiceMate 0.1.0: release notes

I built VoiceMate because speaking is much faster than typing: when you think out loud you give an AI far more context and detail than you would ever type. Press a hotkey, speak, paste. Whisper runs locally, so your voice never leaves your machine. I have used it every working day since March 2026, first on Windows with an NVIDIA card and, after switching to an AMD card, on WSL2, which is why that path is new here and still experimental.

This is the first public release.

## Highlights

- **Dictation to the clipboard:** `Ctrl+Alt+V` starts and stops recording, local Whisper transcribes, and the text is ready to paste into any app or AI tool.
- **Windows tray app (new):** VoiceMate now lives in the system tray. It starts and supervises the speech engine inside WSL2, owns the hotkeys, plays the sound cues and checks that every transcription really reached the clipboard. Anything that did not is kept under **Not copied**, even across restarts.
- **Per-user installer:** `VoiceMate-Setup-0.1.0.exe` installs without an administrator prompt and offers to start VoiceMate when you sign in.
- **Linux, WSL2 and AMD GPUs (experimental):** `make setup` detects NVIDIA, AMD or CPU and installs the matching PyTorch; on AMD a layered speech-to-text chain picks the best backend that works.
- **Five languages:** app, installer and README in English, Português (Brasil), Español, Русский and 简体中文.
- **Voice conversation with Claude (experimental):** `Ctrl+Alt+A` sends what you say to Claude and reads the answer aloud (OmniVoice by default, or Kokoro or VoxCPM2).
- **`make doctor`:** checks microphone, audio, GPU, whisper.cpp and the Claude CLI, and prints a fix for each problem it finds.

## Requirements

- Windows 10 (1809 or newer) or Windows 11, 64-bit, with WSL2 and WSLg; the documented setup uses Ubuntu on Windows 11.
- Inside WSL: Python 3.12, Poetry, git and make, plus the packages listed below.
- A GPU is strongly recommended. The WSL2 path was validated on an AMD Radeon RX 9070 XT with ROCm 7.2 for WSL and the AMD Adrenalin driver 26.2.2 or newer; `make setup` also offers NVIDIA (CUDA) and CPU.
- Only for the conversation with Claude: Node.js 18 or newer and the Claude Code CLI, installed and signed in inside WSL.

## How to install

The installer contains the tray app. The speech engine runs inside WSL2 and is set up once from source; the tray app then starts it for you.

### 1. Set up the engine in WSL2 (once)

1. In Windows, update WSL: `wsl --update`. WSLg, which gives WSL access to your microphone, comes with it.
2. With an AMD GPU: install the AMD Adrenalin driver 26.2.2 or newer in Windows, then ROCm for WSL (track 7.2) inside Ubuntu, following [AMD's guide](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). `rocminfo` must list your GPU.
3. Inside Ubuntu, install the audio and build packages:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Make sure Python 3.12 and [Poetry](https://python-poetry.org/docs/#installation) are installed, then clone VoiceMate into your home folder and run the setup:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detects WSL2 and the GPU, installs the matching PyTorch and the modules you pick
   make doctor   # checks microphone, audio, GPU and binaries, with a fix for each problem
   ```

   `make setup` may offer to install a systemd service that starts the engine with WSL. You do not need it with the tray app.

5. Optional, for the conversation with Claude: install Node.js 18 or newer and the Claude Code CLI inside WSL (`npm install -g @anthropic-ai/claude-code`), then run `claude` once to sign in.

More detail and troubleshooting: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.1.0/docs/wsl2.md).

### 2. Download and check the installer

Download `VoiceMate-Setup-0.1.0.exe` and its `.sha256` file from the release page. In PowerShell, in the download folder:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.1.0.exe -Algorithm SHA256).Hash
```

The value must match the one in the `.sha256` file (upper or lower case does not matter). If it does not, do not run the file and download it again.

### 3. Run the installer

1. Open `VoiceMate-Setup-0.1.0.exe`. The installer is not code-signed, so Windows SmartScreen may warn on first run: choose **More info**, then **Run anyway**.
2. Pick the installer language. VoiceMate installs for your user only, without an administrator prompt, into `%LOCALAPPDATA%\Programs\VoiceMate`, and adds itself to the Start menu.
3. Optionally create a desktop shortcut and let VoiceMate start when you sign in, then finish and launch VoiceMate.

### 4. First run

1. The VoiceMate icon appears in the tray. While the engine loads the model (10 to 60 seconds), VoiceMate shows "Starting engine...".
2. The tray app looks for the engine in your default WSL distribution, in common folders such as `~/voice-mate` or `~/workspace/voice-mate`. If it shows "Engine folder not found", open **Settings...** > **General** and set **WSL distro** and **Engine folder**.
3. If a systemd service already runs the engine, the tray app connects to it instead of starting a second one.
4. If a hotkey shows "Used by another app", an old hotkey script (PowerShell or AutoHotkey) is still running: close it and remove its shortcut from `shell:startup`.
5. Try it: press `Ctrl+Alt+V`, speak, press `Ctrl+Alt+V` again, and paste with `Ctrl+V`. `Ctrl+Alt+A` starts the conversation with Claude, if you set it up.

### 5. Pin to the taskbar

Windows does not let installers pin apps, so the first run shows the notification **Pin VoiceMate to the taskbar**. Open Start, search for VoiceMate, right-click it and choose **Pin to taskbar**.

### 6. Change hotkeys, sounds and other settings

Open the tray icon menu > **Settings...**:

- **Hotkeys**: change the dictation and Claude shortcuts.
- **Sounds**: built-in sounds or your own WAV files, and the volume.
- **General**: **Language**, notifications, **Start VoiceMate when I sign in**, **Always show the VoiceMate icon on the taskbar**, the engine (**WSL distro**, **Engine folder**) and **Restart WSL when audio fails** (**Automatically**, **Ask first** or **Never**).

To quit, use the tray icon menu > **Quit VoiceMate**.

## Known limitations

- Linux, WSL2 and AMD support is **experimental**: it has been validated on a single AMD card (Radeon RX 9070 XT) under WSL2.
- The installer is not code-signed, so SmartScreen warns on first run (see step 3).
- On Windows the tray app drives an engine inside WSL2. Running the engine natively on Windows under the tray app is planned for a later release.
- Transcription is pinned to Portuguese by default (derived from `--output-lang pt-BR`) and the tray app has no setting for it yet. To dictate in another language, start the engine yourself in WSL, for example `make run-engine ARGS="--output-lang en"`, and the tray app connects to it.
- On WSL2, whisper.cpp with Vulkan cannot use the GPU (Vulkan there is a software renderer), so AMD transcription goes through openai-whisper on ROCm. The faster CTranslate2-ROCm path is a heavy opt-in build.
- When Windows loses its microphone, WSLg audio can hang until WSL restarts. The tray app can restart WSL for you, following **Restart WSL when audio fails**.
- The voice conversation with Claude is experimental and needs a signed-in Claude Code CLI.
