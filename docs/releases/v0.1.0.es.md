# VoiceMate 0.1.0: notas de la versión

Creé VoiceMate porque hablar es mucho más rápido que escribir: cuando piensas en voz alta le das a la IA mucho más contexto y detalle del que nunca escribirías. Pulsa un atajo, habla, pega. Whisper se ejecuta en local, así que tu voz nunca sale de tu equipo. Lo uso todos los días laborables desde marzo de 2026, primero en Windows con una tarjeta NVIDIA y, después de cambiarla por una AMD, en WSL2; por eso esa ruta es nueva aquí y sigue siendo experimental.

Esta es la primera versión pública.

## Lo más destacado

- **Dictado al portapapeles:** `Ctrl+Alt+V` inicia y detiene la grabación, Whisper transcribe en local y el texto queda listo para pegar en cualquier aplicación o herramienta de IA.
- **Aplicación de bandeja para Windows (nueva):** VoiceMate ahora vive en la bandeja del sistema. Inicia y supervisa el motor de voz dentro de WSL2, registra los atajos, reproduce los sonidos de aviso y comprueba que cada transcripción llegue de verdad al portapapeles. Lo que no llegó se guarda en **No copiadas**, incluso tras reiniciar.
- **Instalador por usuario:** `VoiceMate-Setup-0.1.0.exe` se instala sin pedir permisos de administrador y ofrece iniciar VoiceMate al iniciar sesión.
- **Linux, WSL2 y GPU AMD (experimental):** `make setup` detecta NVIDIA, AMD o CPU e instala el PyTorch adecuado; en AMD, una cadena de reconocimiento de voz por capas elige el mejor backend que funcione.
- **Cinco idiomas:** aplicación, instalador y README en English, Português (Brasil), Español, Русский y 简体中文.
- **Idioma de dictado:** elige en qué idioma hablas en **Configuración...** > **General** > **Idioma de dictado**: **Igual que la interfaz** (por defecto), **Detectar automáticamente** o uno de nueve idiomas. También define el idioma de las respuestas habladas de Claude.
- **Conversación por voz con Claude (experimental):** `Ctrl+Alt+A` envía lo que dices a Claude y lee la respuesta en voz alta (Kokoro u OmniVoice, a elegir en `make setup`; VoxCPM2 está disponible como extra opcional).
- **`make doctor`:** revisa micrófono, audio, GPU, whisper.cpp y la CLI de Claude, e indica cómo corregir cada problema que encuentra.

## Requisitos

- Windows 11, o Windows 10 compilación 19044 o posterior, de 64 bits, con WSL2 y WSLg; la configuración documentada usa Ubuntu en Windows 11. El instalador por sí solo funciona en Windows 10 1809 o posterior, pero el motor necesita WSL2 (Windows 10 1903 o posterior) y WSLg (Windows 10 compilación 19044 o posterior, o Windows 11).
- Dentro de WSL: Python 3.12, Poetry, git y make, además de los paquetes que se indican abajo.
- Se recomienda mucho una GPU. La ruta WSL2 se validó con una AMD Radeon RX 9070 XT, ROCm 7.2 para WSL y el controlador AMD Adrenalin 26.2.2 o posterior; `make setup` también ofrece NVIDIA (CUDA) y CPU, pero no se han probado en WSL2.
- Solo para la conversación con Claude: Node.js 18 o posterior y la CLI de Claude Code, instalada y con la sesión iniciada dentro de WSL.

## Cómo instalar

El instalador incluye la aplicación de bandeja. El motor de voz se ejecuta dentro de WSL2 y se configura una sola vez desde el código fuente; a partir de ahí la aplicación de bandeja lo inicia por ti.

### 1. Configura el motor en WSL2 (una sola vez)

1. En Windows, actualiza WSL: `wsl --update`. WSLg, que da a WSL acceso a tu micrófono, viene incluido.
2. Con una GPU AMD: instala en Windows el controlador AMD Adrenalin 26.2.2 o posterior y, dentro de Ubuntu, ROCm para WSL (versión 7.2), siguiendo la [guía de AMD](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). `rocminfo` debe mostrar tu GPU.
3. Dentro de Ubuntu, instala los paquetes de audio y de compilación:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Comprueba que tienes Python 3.12 y [Poetry](https://python-poetry.org/docs/#installation), clona VoiceMate en tu carpeta personal y ejecuta la configuración:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detecta WSL2 y la GPU, instala el PyTorch adecuado y los módulos que elijas
   make doctor   # revisa micrófono, audio, GPU y binarios, con la solución de cada problema
   ```

   Cuando `make setup` pregunte por el flujo principal, `claude_chat` (el predeterminado) instala los módulos de Claude y de texto a voz para la conversación por voz; elige `clipboard` si solo quieres dictado.

   `make setup` puede ofrecer un servicio de systemd que inicia el motor junto con WSL. Con la aplicación de bandeja no hace falta.

5. Opcional, para la conversación con Claude: instala Node.js 18 o posterior y la CLI de Claude Code dentro de WSL (`npm install -g @anthropic-ai/claude-code`) y ejecuta `claude` una vez para iniciar sesión.

Más detalles y solución de problemas: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.1.0/docs/wsl2.md).

### 2. Descarga y comprueba el instalador

Descarga `VoiceMate-Setup-0.1.0.exe` y su archivo `.sha256` desde la página de la versión. En PowerShell, en la carpeta de descargas:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.1.0.exe -Algorithm SHA256).Hash
```

El valor debe coincidir con el del archivo `.sha256` (da igual que esté en mayúsculas o minúsculas). Si no coincide, no ejecutes el archivo y vuelve a descargarlo.

### 3. Ejecuta el instalador

1. Abre `VoiceMate-Setup-0.1.0.exe`. El instalador no tiene firma de código, así que SmartScreen de Windows puede avisar la primera vez: elige **Más información** y luego **Ejecutar de todas formas**.
2. El instalador usa el idioma de visualización de Windows (o inglés, si no es uno de los cinco). VoiceMate se instala solo para tu usuario, sin permisos de administrador, en `%LOCALAPPDATA%\Programs\VoiceMate`, y se añade al menú Inicio.
3. Si quieres, crea un acceso directo en el escritorio y deja que VoiceMate se inicie al iniciar sesión; después termina y abre VoiceMate.

### 4. Primera ejecución

1. El icono de VoiceMate aparece en la bandeja. Mientras el motor carga el modelo (de 10 a 60 segundos), VoiceMate muestra "Iniciando el motor...".
2. La aplicación busca el motor en la distro predeterminada de WSL, en carpetas habituales como `~/voice-mate` o `~/workspace/voice-mate`. Si aparece "No se encontró la carpeta del motor", abre **Configuración...** > **General** e indica **Distro de WSL** y **Carpeta del motor**.
3. Si un servicio de systemd ya ejecuta el motor, la aplicación se conecta a él en lugar de iniciar otro.
4. Si VoiceMate muestra la notificación "Atajo no disponible", o un atajo muestra "En uso por otra aplicación" en **Configuración...** > **Atajos**, sigue en ejecución un script antiguo de atajos (PowerShell o AutoHotkey): ciérralo y quita su acceso directo de `shell:startup`.
5. Pruébalo: pulsa `Ctrl+Alt+V`, habla, vuelve a pulsar `Ctrl+Alt+V` y pega con `Ctrl+V`. `Ctrl+Alt+A` inicia la conversación con Claude, si la configuraste.
6. Si el micrófono no funciona, abre **Configuración** de Windows > **Privacidad y seguridad** > **Micrófono** (**Privacidad** en Windows 10) y permite que las aplicaciones de escritorio lo usen. Si el audio sigue bloqueado, usa **Reiniciar WSL...** en el menú de la bandeja o ejecuta `wsl --shutdown`.

### 5. Ancla VoiceMate a la barra de tareas

Windows no permite que los instaladores anclen aplicaciones, así que la primera ejecución muestra la notificación **Ancla VoiceMate a la barra de tareas**. Abre Inicio, busca VoiceMate, haz clic derecho sobre él y elige **Anclar a la barra de tareas**.

### 6. Cambia atajos, sonidos y otras opciones

Abre el menú del icono de la bandeja > **Configuración...**:

- **Atajos**: cambia los atajos del dictado y de Claude.
- **Sonidos**: sonidos integrados o tus propios archivos WAV, y el volumen.
- **General**: **Idioma**, **Idioma de dictado** (por defecto **Igual que la interfaz**; también define el idioma de las respuestas habladas de Claude y reinicia el motor), notificaciones, **Iniciar VoiceMate al iniciar sesión**, **Mostrar siempre el icono de VoiceMate en la barra de tareas**, el motor (**Distro de WSL**, **Carpeta del motor**) y **Reiniciar WSL si falla el audio** (**Automáticamente**, **Preguntar antes** o **Nunca**).

Para salir, usa el menú del icono de la bandeja > **Salir de VoiceMate**.

## Limitaciones conocidas

- El soporte de Linux, WSL2 y AMD es **experimental**: se validó con una sola tarjeta AMD (Radeon RX 9070 XT) en WSL2. NVIDIA en WSL2 no se ha probado.
- El instalador no tiene firma de código, así que SmartScreen avisa la primera vez (ver el paso 3).
- En Windows, la aplicación de bandeja controla un motor dentro de WSL2. Ejecutar el motor de forma nativa en Windows con la aplicación de bandeja queda para una versión futura.
- En WSL2, whisper.cpp con Vulkan no puede usar la GPU (allí Vulkan es un renderizador por software), así que la transcripción en AMD pasa por openai-whisper sobre ROCm. La ruta más rápida, CTranslate2-ROCm, es una compilación pesada y opcional.
- Cuando Windows pierde el micrófono, el audio de WSLg puede bloquearse hasta que WSL se reinicie. La aplicación puede reiniciar WSL por ti, según **Reiniciar WSL si falla el audio**.
- La conversación por voz con Claude es experimental y necesita la CLI de Claude Code con la sesión iniciada.
