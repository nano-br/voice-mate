VoiceMate 0.3.0 removes the experimental label, lets the voice assistant speak out of the box with the voices of Windows, adds a microphone button to its window and a step-by-step installation guide in five languages, and makes transcription on AMD GPUs work on ROCm 7. Dictation to the clipboard works as before.

## Highlights

- **Not experimental any more:** VoiceMate has been in daily use since March 2026, so the READMEs and the docs now say what is tested and on what: Windows with an NVIDIA card, and AMD through WSL2 and ROCm 7.2 on a Radeon RX 9070 XT. The voice assistant is still off by default.
- **The assistant speaks out of the box:** with no voice engine set up, it uses the voices Windows already has, for every language installed under Settings > Time and language > Speech. In Settings > **Assistant**, **Voice source:** is **Automatic** by default (the engine's voice when it can speak, the voices of Windows otherwise); **Load voices** and **Test** follow the source you pick.
- **A microphone button in the assistant window:** **Talk** does what `Ctrl+Alt+S` does. One click records, the next one (**Stop and send**) sends the text to the assistant. The line beside it shows the same state as the status window, also for a recording started with the hotkey.
- **A voice that waits and repeats:** the assistant never speaks over a recording, nor while it is transcribed. What a recording cuts is said again afterwards, in the order it was first heard, even with two recordings in a row. A line stopped while the audio device opens does not come back later, and a reply that starts with `<` is read as text by the voice of Windows, no longer as XML.
- **Transcription on AMD GPUs with ROCm 7:** the CTranslate2-ROCm build (faster-whisper on the GPU) now works on a fresh ROCm 7 machine, with MIOpen. The engine setup names a missing MIOpen (`miopen-hip-dev`) before it starts to compile.
- **Claude Code found outside PATH:** the assistant no longer says "Claude Code was not found" when VoiceMate starts at sign-in and the `claude` command lives in `~/.local/bin` or `%APPDATA%/npm`.
- **A step-by-step installation guide in five languages, with screenshots** of every installer page: [docs/install-guide.md](https://github.com/nano-br/voice-mate/blob/v0.3.0/docs/install-guide.md).
- **A demonstration video** of the personal assistant, in Brazilian Portuguese for now: [watch it on YouTube](https://youtu.be/T9H30G-AbZo).

## Download

- **`VoiceMate-Setup-0.3.0.exe`**: the Windows tray app. Per-user install into `%LOCALAPPDATA%\Programs\VoiceMate`; it replaces 0.2.0 in place and keeps your settings. The `.sha256` file next to it holds its SHA-256 checksum.
- The installer contains the tray app only. The speech engine runs inside WSL2 and is set up from source; if you already have it, update it as described in the release notes files (`git pull`, then `make setup`).

## Requirements

- As in 0.1.0: Windows 11, or Windows 10 build 19044 or newer, 64-bit, with WSL2 and WSLg, and the engine set up from source inside WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.3.0/docs/wsl2.md)).
- For the voice assistant: the Claude Code CLI on Windows (the `claude` command), signed in once with `claude auth login`. For the Desktop mode, Claude Desktop open with the screen unlocked.

## Known limitations

- The Desktop mode of the voice assistant types into Claude Desktop through Windows UI Automation: it takes the keyboard for about 2 seconds and clears any draft in that conversation's prompt.
- Conversations the assistant starts with **Full access, never ask (risky)** can change any file and run any command without asking. Keep the default unless you trust what you ask them to do.
- The installer is not code-signed, so SmartScreen warns on first run: choose **More info**, then **Run anyway**.
- AMD support is validated on a single card (Radeon RX 9070 XT) under WSL2, with ROCm 7.2.
- When Windows loses its microphone, WSLg audio can hang until WSL restarts. The tray app can restart WSL for you, following **Restart WSL when audio fails**.
