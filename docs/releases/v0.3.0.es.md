# VoiceMate 0.3.0: notas de la versión

VoiceMate 0.3.0 quita la etiqueta de experimental, hace que el asistente de voz hable desde el primer momento con las voces de Windows, añade un botón de micrófono a su ventana y una guía de instalación paso a paso en cinco idiomas, y hace que la transcripción en GPU AMD funcione en ROCm 7. El dictado al portapapeles funciona como antes.

## Lo más destacado

- **Ya no es experimental:** VoiceMate se usa a diario desde marzo de 2026, así que los README y la documentación ahora dicen qué está probado y en qué: Windows con tarjeta NVIDIA, y AMD mediante WSL2 y ROCm 7.2 en una Radeon RX 9070 XT. El asistente de voz sigue desactivado por defecto.
- **El asistente habla desde el primer momento:** sin ningún motor de voz configurado, usa las voces que Windows ya tiene, para cada idioma instalado en Configuración > Hora e idioma > Voz. En Configuración > **Asistente**, el **Origen de la voz:** viene en **Automática** (la voz del motor cuando puede hablar, las voces de Windows en caso contrario); **Cargar voces** y **Probar** siguen el origen elegido.
- **Un botón de micrófono en la ventana del asistente:** **Hablar** hace lo que hace `Ctrl+Alt+S`. Un clic graba y el siguiente (**Detener y enviar**) envía el texto al asistente. La línea de al lado muestra el mismo estado que la ventana de estado, también para una grabación iniciada con el atajo.
- **Una voz que espera y repite:** el asistente nunca habla encima de una grabación, ni mientras se transcribe. Lo que una grabación corta se dice de nuevo después, en el orden en que se oyó por primera vez, incluso con dos grabaciones seguidas. Una frase detenida mientras se abre el dispositivo de audio no vuelve más tarde, y una respuesta que empieza con `<` la voz de Windows la lee como texto, ya no como XML.
- **Transcripción en GPU AMD con ROCm 7:** la compilación de CTranslate2-ROCm (faster-whisper en la GPU) ahora funciona en una máquina nueva con ROCm 7, con MIOpen. La configuración del motor avisa de que falta MIOpen (`miopen-hip-dev`) antes de empezar a compilar.
- **Claude Code encontrado fuera del PATH:** el asistente ya no dice "No se encontró Claude Code" cuando VoiceMate se inicia al iniciar sesión y el comando `claude` está en `~/.local/bin` o en `%APPDATA%/npm`.
- **Una guía de instalación paso a paso en cinco idiomas, con capturas** de cada página del instalador: [docs/install-guide.es.md](https://github.com/nano-br/voice-mate/blob/v0.3.0/docs/install-guide.es.md).
- **Un vídeo de demostración** del asistente personal, en portugués de Brasil por ahora: [míralo en YouTube](https://youtu.be/T9H30G-AbZo).

## Requisitos

- Como en 0.1.0: Windows 11, o Windows 10 compilación 19044 o posterior, de 64 bits, con WSL2 y WSLg, y el motor configurado desde el código fuente dentro de WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.3.0/docs/wsl2.md)).
- Para el asistente de voz: la CLI de Claude Code en Windows (el comando `claude`), con la sesión iniciada una vez mediante `claude auth login`. Para el modo Desktop, Claude Desktop abierto y la pantalla desbloqueada.

## Actualizar desde 0.2.0

1. Actualiza el motor dentro de WSL, en la carpeta donde clonaste VoiceMate:

   ```bash
   cd ~/voice-mate
   git pull
   make setup    # installs the new dependencies; your earlier answers are the defaults
   make doctor
   ```

   Con una tarjeta AMD en ROCm 7, `make setup` vuelve a compilar CTranslate2-ROCm con MIOpen, que la transcripción en la GPU necesita. Enumera lo que falta antes de compilar; si es MIOpen, instálalo con `sudo apt install -y miopen-hip-dev` y vuelve a ejecutar `make setup`.

2. Descarga y comprueba el instalador (paso 2 más abajo) y después ejecútalo. Si VoiceMate está abierto, el instalador pregunta antes: "VoiceMate se está ejecutando. El instalador lo cerrará, junto con el motor que inició, antes de instalar. ¿Continuar?" Confirma y cierra VoiceMate junto con su motor e instala en el mismo lugar. Tu configuración, los atajos y la lista **No copiadas** se conservan. La casilla "Iniciar automáticamente VoiceMate" se ofrece solo en la primera instalación, así que no vuelve a aparecer.

## Cómo instalar (primera vez)

El instalador incluye la aplicación de bandeja. El motor de voz se ejecuta dentro de WSL2 y se configura una sola vez desde el código fuente; a partir de ahí la aplicación de bandeja lo inicia por ti.

Los mismos pasos, con una captura de cada página del instalador, están en la [guía de instalación](https://github.com/nano-br/voice-mate/blob/v0.3.0/docs/install-guide.es.md).

### 1. Configura el motor en WSL2 (una sola vez)

1. En Windows, actualiza WSL: `wsl --update`. WSLg, que da a WSL acceso a tu micrófono, viene incluido.
2. Con una GPU AMD: instala en Windows el controlador AMD Adrenalin 26.2.2 o posterior y, dentro de Ubuntu, ROCm para WSL (versión 7.2), siguiendo la [guía de AMD](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html). `rocminfo` debe mostrar tu GPU.
3. Dentro de Ubuntu, instala los paquetes de audio y de compilación:

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. Comprueba que tienes Python 3.12 y [Poetry](https://python-poetry.org/docs/#installation), clona VoiceMate en tu carpeta personal y ejecuta la configuración:

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detects WSL2 and the GPU, installs the matching PyTorch and the modules you pick
   make doctor   # checks microphone, audio, GPU and binaries, with a fix for each problem
   ```

   `make setup` pregunta por el modo de transcripción predeterminado (CPU o GPU); puedes cambiarlo después desde el menú de la bandeja. También puede ofrecer un servicio de systemd que inicia el motor junto con WSL. Con la aplicación de bandeja no hace falta.

Más detalles y solución de problemas: [docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.3.0/docs/wsl2.md).

### 2. Descarga y comprueba el instalador

Descarga `VoiceMate-Setup-0.3.0.exe` y su archivo `.sha256` desde la página de la versión. En PowerShell, en la carpeta de descargas:

```powershell
(Get-FileHash .\VoiceMate-Setup-0.3.0.exe -Algorithm SHA256).Hash
```

El valor debe coincidir con el del archivo `.sha256` (da igual que esté en mayúsculas o minúsculas). Si no coincide, no ejecutes el archivo y vuelve a descargarlo.

### 3. Ejecuta el instalador

1. Abre `VoiceMate-Setup-0.3.0.exe`. El instalador no tiene firma de código, así que SmartScreen de Windows puede avisar la primera vez: elige **Más información** y luego **Ejecutar de todas formas**.
2. El instalador se abre en el idioma de visualización de Windows cuando es uno de los cinco; si no, muestra un diálogo de idioma, en inglés. VoiceMate se instala solo para tu usuario, sin permisos de administrador, en `%LOCALAPPDATA%\Programs\VoiceMate`, y se añade al menú Inicio.
3. Si quieres, crea un acceso directo en el escritorio y deja que VoiceMate se inicie al iniciar sesión; después termina y abre VoiceMate.

### 4. Primera ejecución

1. El icono de VoiceMate aparece en la bandeja. Mientras el motor carga el modelo (de 10 a 60 segundos), VoiceMate muestra "Iniciando el motor...".
2. Si aparece "No se encontró la carpeta del motor", abre **Configuración...** > **General** e indica **Distro de WSL** y **Carpeta del motor**.
3. Prueba el dictado: pulsa `Ctrl+Alt+V`, habla, vuelve a pulsar `Ctrl+Alt+V` y pega con `Ctrl+V`.
4. Si el micrófono no funciona, abre **Configuración** de Windows > **Privacidad y seguridad** > **Micrófono** (**Privacidad** en Windows 10) y permite que las aplicaciones de escritorio lo usen. Si el audio sigue bloqueado, usa el menú de la bandeja > **Motor** > **Reiniciar WSL...** o ejecuta `wsl --shutdown`.

### 5. Activa el asistente de voz (opcional)

1. Instala la [CLI de Claude Code](https://docs.claude.com/en/docs/claude-code) en Windows y ejecuta `claude auth login` una vez en una terminal.
2. Pulsa el botón **Asistente** de la ventana de estado (o `Ctrl+Alt+W`). Mientras el asistente está desactivado, su ventana explica cómo activarlo.
3. En **Configuración...** > **Asistente**, elige el **Modo del asistente:**. Para **Una conversación de Claude Desktop**, escribe el título exacto de esa conversación en **Conversación de Desktop:**.
4. Pulsa `Ctrl+Alt+S`, pregunta "¿qué están haciendo mis conversaciones?" y vuelve a pulsar `Ctrl+Alt+S`.

El asistente no necesita una voz configurada: sin ningún motor de voz, habla con las voces de Windows (Configuración > **Asistente** > **Origen de la voz:** en **Automática**). Para hablar sin el atajo, haz clic en **Hablar** en la ventana del asistente; pasa a **Detener y enviar** mientras graba.

El flujo completo, con diagramas: [docs/usage.md](https://github.com/nano-br/voice-mate/blob/v0.3.0/docs/usage.md#voice-assistant).

### 6. Ancla VoiceMate a la barra de tareas

Windows no permite que los instaladores anclen aplicaciones. Abre Inicio, busca VoiceMate, haz clic derecho sobre él y elige **Anclar a la barra de tareas**.

## Limitaciones conocidas

- El modo Desktop del asistente de voz escribe en Claude Desktop mediante la Automatización de la interfaz de usuario de Windows (UI Automation): toma el teclado durante unos 2 segundos y borra cualquier borrador del campo de texto de esa conversación.
- Las conversaciones que el asistente inicia con **Acceso total, nunca preguntar (arriesgado)** pueden modificar cualquier archivo y ejecutar cualquier comando sin preguntar. Mantén el valor predeterminado, a menos que confíes en lo que les pides.
- El instalador no tiene firma de código, así que SmartScreen avisa la primera vez (ver el paso 3).
- El soporte de AMD se validó con una sola tarjeta (Radeon RX 9070 XT) en WSL2, con ROCm 7.2.
- Cuando Windows pierde el micrófono, el audio de WSLg puede bloquearse hasta que WSL se reinicie. La aplicación de bandeja puede reiniciar WSL por ti, según **Reiniciar WSL si falla el audio**.
