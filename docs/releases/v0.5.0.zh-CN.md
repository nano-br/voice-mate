# VoiceMate 0.5.0 发行说明

VoiceMate 0.5.0 让语音助手主动行事：它会找到你说的那段对话，读取它，向它询问所需信息，再把答案告诉你。它还能替你持续关注对话、记住你的长期指令，并向已关闭的会话发送消息。VoiceMate 现在可以使用你自己运行的转写服务进行转写，参考文档也提供五种语言版本。

## 亮点

- **助手主动行事：** 它会找到你说的那段对话，读取它，向它询问所需信息，再把答案告诉你。只有真正需要你决定的事才会问你：删除、花钱、发布、口味偏好。只要笔记对回答有帮助，它也会直接读取你的笔记库，不必先问；设置 > **助手** 会建议 Obsidian 已知的笔记库。指南：[docs/assistant.zh-CN.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/assistant.zh-CN.md)。

- **关注：** 对某段对话说“盯着它”，助手就会在它每结束一轮时汇报，直到你说停止（超过 12 小时没有新一轮则结束），相近时间结束的轮次会合并汇报。**等待中** 列表会连同每份记录已读到的位置一起保存，因此在 VoiceMate 关闭期间结束的一轮仍会被汇报，到期的条目会带着一条说明移出。

- **长期指令：** 你给助手的规则（“从现在起……”）会被保存（最多 40 条，每条 300 个字符），并在每次会话中遵守。只有对你本人话语的回复才能添加或删除规则。

- **已关闭的会话也能收到消息：** VoiceMate 会在后台、在该会话自己的文件夹中恢复已关闭的终端、IDE 或 Remote Control 会话，答案会像其他答案一样返回。除非你设置 `[assistant] resume_permission_mode`（`default`、`acceptEdits` 或 `plan`；`bypassPermissions` 会被拒绝），否则不会传入任何权限模式。未送达的消息会被汇报。正在使用的会话仍然只读，客户端自带会话工具时可通过这些工具访问。

- **你自己的转写服务：** VoiceMate 可以通过 `voicemate-stt` 协议，使用你自己运行的语音转文字服务进行转写，它是语音提供方协议在转写方面的对应协议。引擎参数：`--stt-engine external`、`--stt-url`、`--stt-options` 和 `--no-stt-fallback`。服务无法使用时，录音由内置引擎转写，除非指定了 `--no-stt-fallback`。`make stt-provider-check` 用于检查服务，`make stt-provider-example` 运行一个参考服务。详情：[docs/stt-provider-protocol.zh-CN.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/stt-provider-protocol.zh-CN.md)。

- **五种语言的文档：** 架构、配置、转写提供方协议、常见问题和使用说明现在也有葡萄牙语、西班牙语、俄语和简体中文版本，与助手指南和安装指南一样。

- **更少丢失的回复：** 当助手在回复模型之外作答时（对话被总结后它可能丢失该模型），VoiceMate 会提醒它一次，让答案被重新说出并朗读，而不只是显示。开始新一轮时，不再朗读或执行上一条回复。

## 系统要求

- 与 0.1.0 相同：Windows 11，或 Windows 10 内部版本 19044 或更高，64 位，并安装 WSL2 和 WSLg，且已在 WSL 中从源码配置好引擎（[docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/wsl2.md)）。
- 使用语音助手需要：Windows 上的 Claude Code CLI（`claude` 命令），并已通过 `claude auth login` 登录一次。使用 Desktop 模式时，需要打开 Claude Desktop 且屏幕未锁定。

## 从 0.4.0 升级

1. 在 WSL 中更新引擎，进入你克隆 VoiceMate 的目录：

   ```bash
   cd ~/voice-mate
   git pull
   make setup    # installs the new dependencies; your earlier answers are the defaults
   make doctor
   ```

2. 下载并校验安装程序（见下文第 2 步），然后运行它。如果 VoiceMate 正在运行，安装程序会先询问：“VoiceMate 正在运行。安装程序将在安装前关闭它及其启动的引擎。是否继续？”确认后，它会把 VoiceMate 连同引擎一起关闭，然后就地安装。你的设置、快捷键和 **未复制** 列表会保留。“自动启动 VoiceMate”复选框只在第一次安装时提供，所以不会再出现。

3. 你的配置和脚本都不需要调整：没有任何设置、参数或键被删除或改名，新增的都是可选项。0.5.0 是 0.x 系列中的 MINOR 版本，这类版本可能需要调整，但这一版不需要。助手的指令（它的 skill）有了新版本：如果你编辑过自己的副本，VoiceMate 会保留它，并把新版本放在旁边，文件名以 `.new` 结尾。请合并，或删除你的副本。

## 安装步骤（首次安装）

安装程序只包含托盘应用。语音引擎运行在 WSL2 中，需要从源码配置一次；之后由托盘应用替你启动。

同样的步骤，加上安装程序每一页的截图，见[安装指南](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/install-guide.zh-CN.md)。

### 1. 在 WSL2 中配置引擎（只需一次）

1. 在 Windows 中更新 WSL：`wsl --update`。WSLg 会随之安装，它让 WSL 能使用你的麦克风。
2. 如果使用 AMD 显卡：在 Windows 中安装 AMD Adrenalin 26.2.2 或更高版本的驱动，并按照 [AMD 官方指南](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html) 在 Ubuntu 中安装 WSL 版 ROCm（7.2 版本线）。`rocminfo` 应能列出你的 GPU。
3. 在 Ubuntu 中安装音频和编译所需的软件包：

   ```bash
   sudo apt install -y libportaudio2 libasound2-plugins pulseaudio-utils wl-clipboard \
                       git cmake build-essential libvulkan-dev glslc vulkan-tools \
                       spirv-headers spirv-tools glslang-tools espeak-ng
   ```

4. 确认已安装 Python 3.12 和 [Poetry](https://python-poetry.org/docs/#installation)，然后把 VoiceMate 克隆到你的主目录并运行配置：

   ```bash
   git clone https://github.com/nano-br/voice-mate.git ~/voice-mate
   cd ~/voice-mate
   make setup    # detects WSL2 and the GPU, installs the matching PyTorch and the modules you pick
   make doctor   # checks microphone, audio, GPU and binaries, with a fix for each problem
   ```

   `make setup` 会询问默认的转写模式（CPU 或 GPU），之后可在托盘菜单中切换。它还可能提议安装一个随 WSL 启动引擎的 systemd 服务。使用托盘应用时不需要它。

更多细节和故障排查：[docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/wsl2.md)。

### 2. 下载并校验安装程序

从发布页面下载 `VoiceMate-Setup-0.5.0.exe` 及其 `.sha256` 文件。在下载目录中打开 PowerShell，运行：

```powershell
(Get-FileHash .\VoiceMate-Setup-0.5.0.exe -Algorithm SHA256).Hash
```

输出的值必须与 `.sha256` 文件中的值一致（不区分大小写）。如果不一致，请不要运行该文件，并重新下载。

### 3. 运行安装程序

1. 打开 `VoiceMate-Setup-0.5.0.exe`。安装程序没有代码签名，因此首次运行时 Windows SmartScreen 可能会发出警告：点击 **更多信息**，然后点击 **仍要运行**。
2. 如果 Windows 的显示语言是这五种之一，安装程序会直接使用该语言；否则会显示一个英文的语言选择对话框。VoiceMate 只为当前用户安装，无需管理员权限，安装位置为 `%LOCALAPPDATA%\Programs\VoiceMate`，并会添加到“开始”菜单。
3. 可以按需创建桌面快捷方式，并让 VoiceMate 在登录时启动；然后完成安装并打开 VoiceMate。

### 4. 首次运行

1. VoiceMate 图标会出现在托盘中。引擎加载模型期间（10 到 60 秒），VoiceMate 会显示“正在启动引擎...”。
2. 如果显示“未找到引擎文件夹”，请打开 **设置...** > **常规**，填写 **WSL 发行版** 和 **引擎文件夹**。
3. 试一试听写：按 `Ctrl+Alt+V`，说话，再按一次 `Ctrl+Alt+V`，然后用 `Ctrl+V` 粘贴。
4. 如果麦克风无法使用，请打开 Windows **设置** > **隐私和安全性** > **麦克风**（Windows 10 中为 **隐私**），允许桌面应用使用麦克风。如果音频仍然卡住，请使用托盘菜单 > **引擎** > **重启 WSL...**，或运行 `wsl --shutdown`。

### 5. 开启语音助手（可选）

1. 在 Windows 上安装 [Claude Code CLI](https://docs.claude.com/en/docs/claude-code)，并在终端中运行一次 `claude auth login`。
2. 点击状态窗口中的 **助手** 按钮（或按 `Ctrl+Alt+W`）。助手关闭时，它的窗口会说明如何开启。
3. 在 **设置...** > **助手** 中选择 **助手模式：**。如果选择 **一个 Claude Desktop 对话**，请在 **Desktop 对话：** 中输入该对话的准确标题。
4. 按 `Ctrl+Alt+S`，问一句 "what are my conversations doing?"（我的对话在做什么？），然后再按一次 `Ctrl+Alt+S`。

助手不需要设置声音：没有语音引擎时，它会用 Windows 的语音朗读（设置 > **助手** > **语音来源：** 为 **自动**）。想不用快捷键说话，可以点助手窗口中的 **说话**；录音时它会变成 **停止并发送**。

完整流程及图示：[docs/usage.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/usage.md#voice-assistant)。

### 6. 固定到任务栏

Windows 不允许安装程序固定应用。打开“开始”菜单，搜索 VoiceMate，右键单击它并选择 **固定到任务栏**。

## 已知限制

- 语音助手的 Desktop 模式通过 Windows UI Automation 向 Claude Desktop 输入内容：它会占用键盘约 2 秒，并清除该对话输入框中的任何草稿。
- 助手以 **完全访问，从不询问（有风险）** 开启的对话，可以在不询问的情况下修改任何文件、运行任何命令。除非你信任交给它们的任务，否则请保持默认设置。
- 安装程序没有代码签名，因此首次运行时 SmartScreen 会发出警告（见第 3 步）。
- AMD 支持只在一块显卡（Radeon RX 9070 XT）上于 WSL2 中验证过，使用 ROCm 7.2。
- Windows 丢失麦克风后，WSLg 的音频可能会卡住，直到 WSL 重启。托盘应用可以按照 **音频故障时重启 WSL** 的设置替你重启 WSL。
