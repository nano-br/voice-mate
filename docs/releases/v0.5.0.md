VoiceMate 0.5.0 makes the voice assistant take the initiative: it finds the conversation you mean, reads it, asks it what it needs and tells you the answer. It can also keep watching conversations for you, remember your standing instructions and send messages to closed sessions. VoiceMate can now transcribe with a speech-to-text service you run yourself, and the reference documentation is available in five languages.

## Highlights

- **The assistant takes initiative:** it finds the conversation you mean, reads it, asks it what it needs and tells you the answer. It asks you only for real decisions: deleting, spending, publishing, matters of taste. It also reads your notes vault whenever the notes help answer you, without asking first, and Settings > **Assistant** suggests the vaults Obsidian already knows. Guide: [docs/assistant.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/assistant.md).

- **Watches:** say "keep an eye on" a conversation and the assistant reports every turn it finishes until you say stop (up to 12 hours without a new turn), grouping turns that end close together. The **Waiting for** list is saved with how far each transcript was read, so a turn that ended while VoiceMate was closed is still reported, and an entry whose time ran out leaves with a note.

- **Standing instructions:** a rule you give the assistant ("from now on...") is kept, up to 40 rules of 300 characters each, and followed in every session. Only a reply to your own words can add or remove one.

- **Closed sessions can receive a message:** VoiceMate resumes a closed terminal, IDE or Remote Control session in the background, in its own folder, and the answer comes back like any other. It passes no permission mode unless you set `[assistant] resume_permission_mode` (`default`, `acceptEdits` or `plan`; `bypassPermissions` is refused). A message that was not delivered is reported. A session in use stays read only, reachable through the client's own session tools when it has them.

- **Your own transcription service:** VoiceMate can transcribe with a speech-to-text service you run yourself, through the `voicemate-stt` protocol, the transcription sibling of the TTS provider protocol. Engine flags: `--stt-engine external`, `--stt-url`, `--stt-options` and `--no-stt-fallback`. When the service cannot be used, the recording is transcribed by the built-in engine, unless `--no-stt-fallback` is given. `make stt-provider-check` checks a service and `make stt-provider-example` runs a reference one. Details: [docs/stt-provider-protocol.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/stt-provider-protocol.md).

- **Documentation in five languages:** architecture, configuration, the STT provider protocol, troubleshooting and usage now also exist in Portuguese, Spanish, Russian and Simplified Chinese, like the assistant guide and the installation guide.

- **Fewer lost replies:** when the assistant answers outside its reply model (it can lose the model when its conversation is summarized), VoiceMate tells it once, so the answer is said again and spoken instead of only shown. Starting a new turn no longer speaks or acts on the previous reply.

## Download

- **`VoiceMate-Setup-0.5.0.exe`**: the Windows tray app. Per-user install into `%LOCALAPPDATA%\Programs\VoiceMate`; it replaces 0.4.0 in place and keeps your settings. The `.sha256` file next to it holds its SHA-256 checksum.
- The installer contains the tray app only. The speech engine runs inside WSL2 and is set up from source; if you already have it, update it as described in the release notes files (`git pull`, then `make setup`).

## Requirements

- As in 0.1.0: Windows 11, or Windows 10 build 19044 or newer, 64-bit, with WSL2 and WSLg, and the engine set up from source inside WSL ([docs/wsl2.md](https://github.com/nano-br/voice-mate/blob/v0.5.0/docs/wsl2.md)).
- For the voice assistant: the Claude Code CLI on Windows (the `claude` command), signed in once with `claude auth login`. For the Desktop mode, Claude Desktop open with the screen unlocked.

## Known limitations

- The Desktop mode of the voice assistant types into Claude Desktop through Windows UI Automation: it takes the keyboard for about 2 seconds and clears any draft in that conversation's prompt.
- Conversations the assistant starts with **Full access, never ask (risky)** can change any file and run any command without asking. Keep the default unless you trust what you ask them to do.
- The installer is not code-signed, so SmartScreen warns on first run: choose **More info**, then **Run anyway**.
- AMD support is validated on a single card (Radeon RX 9070 XT) under WSL2, with ROCm 7.2.
- When Windows loses its microphone, WSLg audio can hang until WSL restarts. The tray app can restart WSL for you, following **Restart WSL when audio fails**.
